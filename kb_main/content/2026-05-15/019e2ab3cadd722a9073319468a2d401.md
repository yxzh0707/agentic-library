# Round 1 Ablation Queue

> 数据到位后**无需思考**，按 P0 → P3 顺序执行。每条都有 hypothesis、tags、完整 CLI。
> 所有命令假设：数据在 `data/round1/round1_train.parquet`，已通过 schema_validator。

## 执行前检查（T+0 ~ T+25）

按 `round1_playbook.md` 完成：
1. Schema 验证通过
2. EDA 得出 `max_seq_len`、`dense_pad_dim`、`vocab_size` 建议值
3. 确认 baseline (`P0`) 跑出 mean±std，且 std << 关心的 delta（否则所有 ablation 不可信，去扩 seed 数）

---

## P0 — Baseline（必跑，作为后续 delta 参考系）

**Hypothesis**: UniRec-Hybrid (no-GLN) 在 Round 1 数据上可复现 demo 的稳定训练轨迹。
**Expected**: 给出 AUC 和 noise_bound（3-seed std）基线，供后续所有 ablation 参照。

```bash
PYTHONPATH=. python scripts/run_experiment.py \
  --data data/round1/round1_train.parquet \
  --name round1_p0_baseline \
  --model unirec_hybrid \
  --seeds 7,42,123 \
  --epochs 10 --batch-size 64 --lr 1e-3 \
  --tags baseline,unirec_hybrid
```

**完成后立刻做一件事**：用 3-seed std 更新 `src/training/loop.py` 里 `_noise_bound_for`：
```python
if "round1" in path:
    return <observed_std>  # e.g., 0.015
```

## P1 — Runnable via CLI toggle（零实现成本，最高优先级）

### P1.1 — NAL aux loss（predicted +2.18%）

**Hypothesis**: DHEN 论文的 Next Action Loss 在 Round 1 数据上恢复论文报告的 +2.18% AUC；demo 上的 -2.68% 是样本量太小。
**Expected_delta_sign**: +1, magnitude ≈ 0.022
**Risk**: NAL 需要序列长度 ≥ 某阈值；若 Round 1 数据仍有短序列占比高，可能无效

```bash
PYTHONPATH=. python scripts/run_experiment.py \
  --data data/round1/round1_train.parquet \
  --name round1_p1_nal \
  --model unirec_hybrid \
  --seeds 7,42,123 \
  --epochs 10 --lr 1e-3 \
  --use-nal --nal-weight 0.3 \
  --tags nal,aux_loss,dhen \
  --expected-delta-sign 1
```

**若 delta 不显著**：试 `--nal-weight 0.1` / `0.5` / `1.0` 做 weight sweep（单 seed 先粗筛，选最佳再 3-seed 确认）

---

### P1.2 — Re-verify HeadMixing（predicted -8.5%，当前唯一勉强超 demo 噪声的结论）

**Hypothesis**: 去掉 HeadMixing 应显著降 AUC；这是**最可能在 Round 1 上真正超噪声的 prior**。
**Expected_delta_sign**: -1, magnitude ≈ 0.085
**为什么 P1**: 如果 Round 1 上这条 demo 结论翻了（delta 在 Round 1 噪声内），说明整个 UniRec-Hybrid 的"跨 token 交互必要"假设要重审

```bash
PYTHONPATH=. python scripts/run_experiment.py \
  --data data/round1/round1_train.parquet \
  --name round1_p1_ablate_head_mixing \
  --model unirec_hybrid \
  --seeds 7,42,123 \
  --epochs 10 --lr 1e-3 \
  --no-head-mixing \
  --tags ablation,head_mixing,token_interaction --ablation-removes head_mixing \
  --expected-delta-sign -1
```

**姊妹实验（顺便跑）**：把 `--no-head-mixing` 换成 `--no-target-aware` 或 `--no-per-token-ffn`，tag 对应换成 `target_aware` / `per_token_ffn`。三个 ablation 合起来给出架构核心三件套在 Round 1 上的独立贡献度。

---

### P1.3 — Re-enable GLN（demo 上被推翻，但 noise 主导）

**Hypothesis**: Demo 上 `no-GLN > GLN` 的 +0.4% 本身在噪声内（5.7% >> 0.4%）；Round 1 数据量大后 GLN 可能恢复论文报告的 +0.8%。
**Expected_delta_sign**: +1 (re-enabling), magnitude ≈ 0.008
**Status**: demo refuted 但证据弱，值得一次 Round 1 复测

```bash
PYTHONPATH=. python scripts/run_experiment.py \
  --data data/round1/round1_train.parquet \
  --name round1_p1_gln_revisit \
  --model unirec_hybrid \
  --seeds 7,42,123 \
  --epochs 10 --lr 1e-3 \
  --use-gln \
  --tags gln,normalization,mtgr \
  --expected-delta-sign 1
```

## P2 — 需要小量代码改动

### P2.1 — depth=3（DHEN 论文说 3 层起过拟合，demo 没测过）

**Hypothesis**: 验证 DHEN 的"2 层甜蜜点"结论在 Round 1 上是否成立。
**Expected_delta_sign**: -1 (从 2→3 应略降), magnitude ≈ 0.005

```bash
PYTHONPATH=. python scripts/run_experiment.py \
  --data data/round1/round1_train.parquet \
  --name round1_p2_depth3 \
  --model unirec_hybrid --num-layers 3 \
  --seeds 7,42,123 \
  --epochs 10 --lr 1e-3 \
  --tags depth_choice,dhen,layer_depth \
  --expected-delta-sign -1
```

### P2.2 — hidden_dim=256（model capacity，论文无明确 claim）

**Hypothesis**: 当前 hidden_dim=128 可能对 Round 1 数据偏小（demo 数据量小时够用，但 Round 1 大数据集可能欠拟合）。
**Expected_delta_sign**: +1, magnitude unknown (0.005~0.02)
**Risk**: 2x 参数量，推理延迟可能翻倍。跑前先 `profile_latency.py` 看 budget

```bash
# 先看延迟预算
PYTHONPATH=. python scripts/profile_latency.py \
  --checkpoint <baseline.pt> --data data/round1/round1_test.parquet

# 若预算 OK，跑 hidden_dim=256 版本
PYTHONPATH=. python scripts/run_experiment.py \
  --data data/round1/round1_train.parquet \
  --name round1_p2_hidden256 \
  --model unirec_hybrid --hidden-dim 256 --num-heads 8 \
  --seeds 7,42,123 \
  --epochs 10 --lr 1e-3 \
  --tags capacity,hidden_dim \
  --expected-delta-sign 1
```

### P2.3 — LR schedule 调优（cosine + warmup，B 里已 toggle）

**Hypothesis**: 常数 LR 1e-3 是 demo 最省事的选择；Round 1 用 cosine decay + warmup 能榨出末端收益。
**Expected_delta_sign**: +1, magnitude ≈ 0.005~0.01

```bash
PYTHONPATH=. python scripts/run_experiment.py \
  --data data/round1/round1_train.parquet \
  --name round1_p2_cosine_lr \
  --model unirec_hybrid \
  --seeds 7,42,123 \
  --epochs 10 --lr 1e-3 \
  --lr-schedule cosine --warmup-steps 500 \
  --tags lr_schedule,cosine,hparam
```

## P3 — 需要真正实现（Day 3+ 再考虑，需要实验预算支持）

### P3.1 — Cross features（MTGR 强先验：丢弃所有收益归零）
**实现量**: 中等。在 `UniRecHybrid.forward` 加一层 cross-product feature 生成（user × item × domain 的 pairwise or hash-trick）。
**Risk**: 会改变模型结构，所有 ablation 需基于新 baseline 重算。
**等条件**: Baseline AUC 已稳定，有 1~2 天预算。

### P3.2 — [SEP] token 序列边界（OneTrans 先验 +0.32%）
**实现量**: 小。在 `flat_reader.py` 的序列拼接处插入特殊 ID。
**等条件**: P1 全部跑完后。

### P3.3 — 混合参数化 S/NS tokens（OneTrans 先验 +0.29%）
**实现量**: 较大。需要区分哪些 token "shared"、哪些 "NS-independent"。
**等条件**: Baseline + P1 确认无效优化后再考虑。

### P3.4 — 动态 Masking 三规则（MTGR 先验）
**实现量**: 中。修改 attention mask 构造逻辑。
**Risk**: 与 HeadMixing（parameter-free）的 cross-token 策略可能冲突。
**等条件**: 若 HeadMixing 在 Round 1 失效（见 P1.2），优先考虑此条替代方案。

### P3.5 — Pre-training（MLM / 对比学习）
**触发条件**: 数据量 > 10K **且**前述 P1/P2 全部榨干后仍有 token budget。

### P3.6 — Session / hierarchical 序列建模
**触发条件**: EDA 发现数据有明显 session 结构（同一 user 多次 session）。

## 节奏建议

| Day | 任务 |
|-----|------|
| 1 (开榜日) | P0 → 首提交（榜上占位最重要） |
| 2 | P1.1 (NAL) + P1.2 (HeadMixing re-verify) + P1.3 (GLN revisit) |
| 3 | 根据 Day 2 结果选 P2 中 1~2 项；失败项归档，成功项考虑进下一版 baseline |
| 4~5 | P2 补完；观察 leaderboard 位置，决定是否启动 P3 |
| 6+ | 只在 P0~P2 完全榨干后才碰 P3 |

## 终止条件（Circuit Breaker）

- 连续 3 个 P1/P2 ablation AUC 变化均在 3-seed std 内 → 暂停，重新审视 noise_bound 和 prior magnitude 估计
- 单日实验 ≥15 (见 `check_circuit_breakers`) → 强制暂停，做 knowledge consolidation
- P1 全部跑完后最佳 AUC vs P0 提升 < 0.005 → 说明现有 prior 架构已饱和，转向 P3 或 feature engineering

## 结果回写

每条跑完后，`auto_update_domain_hints` 会：
- Working 区写一条"Significant AUC change"
- 若 delta 超 Round 1 noise_bound 且方向与 prior 不符 → JSONL 记 `knowledge_events.jsonl` + markdown 写 "Prior Contradiction"

人工晋升规则（L3 自动晋升器未实现，手工做）：
- 同 tag 下 ≥2 个实验 mean 方向一致且 |mean| > noise_bound → 从 Working 晋升到 Episodic
- 若跨 Round 稳定（Round 1 + 未来 Round 2） → 晋升到 Semantic
