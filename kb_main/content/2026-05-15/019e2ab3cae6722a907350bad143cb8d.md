## 2. What These Experiments Test

### Architecture change (identical for I-665 and I-666)

**Inject MC-MLCC Local Compressor as residual between `output_proj` and `clsfier`** in PCVRHyFormer.

Code path: `experiments/I-665_mcmlcc_local_compressor/code/model.py`

```python
class LocalCompressor(nn.Module):
    """Block-wise low-rank cross interaction (arXiv 2602.12041 Sec 3.3).
       Splits d_model=64 into K blocks of dim block_dim=D/K.
       For each block: x @ W_compress -> elementwise square -> @ W_expand.
       Residual gated by learnable gamma=0 init (so model starts identical to I-643)."""
    # ~30 lines, K=4 blocks; einsum 'bkd,kde->bke' for compress, 'bke,ked->bkd' for expand.
```

Injection (in `forward()` and `predict()`):
```python
output = self.output_proj(all_q.view(B, -1))          # (B, 64)
output = output + self.local_compressor(output)        # I-665/I-666 added line
logits = self.clsfier(output)
```

**Why gamma=0 init**: model is behaviorally identical to I-643 at step 0. If it can't even reach I-643 baseline, mechanism is harmful. If it strictly improves, mechanism contributes.

**Diff between I-665 and I-666**: ONLY `e_prime` argument (8 vs 16). This is a pure rank-ablation pair.

| Variant | e_prime | New dense params | Paper Table 5 ref |
|---|---|---|---|
| I-665 | 8 | 1025 | Bilibili 0.8301 |
| I-666 | 16 | 2049 | Bilibili 0.8300 (slight regression vs E'=8 on Bilibili — see Caveat below) |

### Caveat on I-666 prior

Paper Table 5 actually shows E'=16 (0.8300) slightly UNDER E'=8 (0.8301) on Bilibili. So I-666's prior is "test if our smaller dataset (4M rows vs paper's 10B+) prefers higher rank, OR confirms paper's finding". The expected delta for I-666 is conservative.
