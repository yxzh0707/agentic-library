# I-673 — IF-DFM-Lite Timestamp Recency Weight

## Design

Forked from `experiments/I-670_mldcn_stable_cross/code/` and applies a training-only timestamp sample weight inspired by IF-DFM. The model architecture and inference path are unchanged from I-670.

## Mechanism

For each batch, the trainer reads the already-emitted top-level `timestamp` tensor and computes:

`day_index = floor((timestamp - global_min_ts) / 86400)`

`weight = clamp(exp(gamma_recency * day_index), 0.5, 2.0)`

The optimized loss is `(BCE(logit, y, reduction='none') * weight).mean()`. `gamma_recency` is a trainer-owned `nn.Parameter` optimized by the dense AdamW optimizer and initialized to zero, so the first step is exactly I-670 behavior.

## Safety Constraints

- `model.py` is intentionally unchanged; inference remains deterministic and identical to I-670.
- `infer.py` is intentionally unchanged.
- Uses only the top-level `timestamp`, not `label_time`.
- Weight is bounded to `[0.5, 2.0]`.
- Dataset audit confirmed `PCVRParquetDataset._convert_batch()` already reads `timestamp` from parquet and emits it as `torch.from_numpy(timestamps)` in each batch dict.
