design:
  windows: [3600, 21600, 86400, 604800, 2592000]  # 1h, 6h, 1d, 7d, 30d
  per-item statistics (per window):
    - n_exposure (any row with this item_id at time t' in [t-W, t))
    - n_click    (rows with label_type >= 1)
    - n_conversion (rows with label_type == 2)
  derived per-window:
    - log1p(n_exposure / n_click / n_conversion) — long-tail compression
    - smooth_ctr = (n_click + α * global_ctr) / (n_exposure + α)
    - smooth_cvr = (n_conversion + α * global_cvr) / (n_exposure + α)
    - α (Bayesian prior strength) = 100 (typical, will tune)
  cold_start_fallback:
    - threshold: n_exposure < 10 in any window → use category-mean
    - category source: TBD (need schema audit — see implementation plan)

total_new_features_per_row: |
  5 windows × (3 raw counts → log1p) + 5 windows × 2 smoothed ratios = 25
  (or fewer after ablation; start with 25 dense features)

new_dense_params: |
  ~6400 (item_dense_dim 0 → 25, then 25 × 64 d_model × 4 ns_chunks = ~6400)
