## Notes

New parameters are only the 4 per-domain dense projections. With default
`d_model=64`, the increase is `4 * (16*64 + 64) = 4352` parameters. They are
not `nn.Embedding` modules, so the cold-restart high-cardinality embedding
reset path does not reinitialize them.
