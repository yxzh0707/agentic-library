# Experiment Meta

## Proposed Experiment

- Name: `I-670 mldcn_stable_cross`
- Axis: Feature interaction / explicit cross branch over stable attributes
- Recommendation: `GO`

## Hypothesis

A tiny ML-DCN-style low-rank explicit cross over stable user/item attribute fids plus user_dense can add transferable polynomial interactions without relying on learned user_id/item_id representations.

## Why This Is Not a Closed-Axis Repeat

- Closed-axis check: no hit; this does not add cate-OOF features, token gates, loss changes, ensembling, or d_model-path attention changes.
- Structural distinction: the branch is separate from the HyFormer sequence/NS attention path and is zero-gated by `gamma_cross=0.0` at initialization.
- Leakage guard: cross inputs are only per-fid `user_int_feats_*` / `item_int_feats_*` tokenizer embeddings and `user_dense_feats`; no global user_id or item_id embedding is introduced.

## Paper / Prior Support

- Local paper prior: +EV from SPEC-cited 2026 ML-DCN masked low-rank explicit cross recipe.
- Relevant prior citations: `experiments/I-670_mldcn_stable_cross/SPEC.md` cites ML-DCN (Pinterest, arXiv 2602.09194, 2026), DCN^2 (AdKDD 2025), DLF (SIGIR 2025), and Field-Aware Transformer (arXiv 2025).

## Expected Outcome

- Expected validation movement: small / noisy; valid delta below 0.001 should not be treated as predictive.
- Expected LB movement: possible positive transfer by adding stable feature-axis interactions to I-643.
- Failure mode to watch: extra branch overfits or the static field mask learns unhelpful crosses; if LB is flat/down, do not iterate by adding gates.

## Evaluation Plan

- Primary metric: ROC-AUC
- Secondary checks: LogLoss, calibration, latency p95 if applicable
- Stop condition: one Taiji evaluation unless I-670 promotes; only then consider the sibling rank/depth ablation.
