## Notes

**为什么选 alpha=0.25 / gamma=2.0**：
- 这是 Lin et al. 2017 RetinaNet 论文的经典配置，跨多个稀有事件分类任务验证有效
- alpha=0.25 给正样本权重 0.25 / 负样本权重 0.75 → 反比例稀有事件加权
- 我们数据 CVR ~5%，alpha=0.25 是合理起点（更激进的 0.1 留给后续 sweep）
- gamma=2.0 是 sweet spot；γ=0 退化为 BCE，γ→∞ 只学最难样本

**为什么这是 I-625 的"零代码"扩展**：
- trainer.py:458 已有 `if self.loss_type == 'focal': loss = sigmoid_focal_loss(...)` 分支
- train.py CLI 早就暴露 `--loss_type / --focal_alpha / --focal_gamma`
- I-630 唯一改动是 run.sh 把这三个 flag 启用——这是真正的"flag 开关式"实验

**风险点**：
- focal loss 早期训练 loss 数值范围更小，可能影响 LR scheduler / patience。**保留 patience=5 不动**
- amp + focal 组合需要数值稳定性验证；utils.sigmoid_focal_loss 已经是数值稳定实现（用 logits 直接算，避免 log(sigmoid) 下溢）

**和 I-617 / I-616 v2 的关系**：
- 完全正交（不同轴）——LB 直接告诉我们损失函数轴是否独立 +EV
- 若 I-630 +EV 且 I-616/I-617 任一 +EV → I-626 stack 候选 = I-625 + focal + 时间 winner
