## Notes

**Why this experiment matters even with low prior**:
- I-615 v2 KILL was ambiguous evidence: could be coupling bug OR axis saturation.

- Cost: 1 GPU run + 1 LB slot. ROI: high (closes open scientific question).

- `SEQ_TIME_PERIODS` retained as alias to `SEQ_ABS_PERIODS` so any external caller
  (infer.py fallback, scripts/) doesn't break. New code should use the explicit
  ABS / GAP names.
- Padding/wipe semantics unchanged from I-625 (scoped wipe of gap slice only).
