# I-673 — IF-DFM-Lite via timestamp-based sample weight

## Hypothesis
Apply a lightweight, IF-DFM-inspired (AAAI 2026 arXiv 2502.01669) sample reweighting during training to bias the model toward recent (closer to test distribution) samples. Mechanism is training-only — no inference change, no feature added → no test-parquet leak risk.

Expected lift +0.002~+0.005 over I-670 SOTA (LB 0.825484) per IF-DFM Taobao subset reported +0.0028.

## Base
- Fork from `experiments/I-670_mldcn_stable_cross/code/` (NEW SOTA)
- ONLY changes: trainer.py loss block + train.py args + run.sh env

## Why this is NOT Pattern B
Pattern B (5/5 KILL per `decision_log:1010`) is "pure reweighting/normalization based on existing label distribution" (focal/pairwise). I-673 weights samples by **timestamp** (a feature the model previously ignored at loss level) — this injects NEW temporal-distribution information into training. The weight is bounded and learnable, mitigating over-bias.

## Constraints
- Use sample-level `timestamp` (top-level column) — NOT label_time (avoids any leak path)
- Weight applied ONLY during training; inference unchanged
- weight clamped to [0.5, 2.0] for stability
- γ (weight slope) initialized to 0 (model behavior = I-670 at step 0; same gamma-zero trick that worked for I-670 ML-DCN cross)

## Mechanism
```python
# In trainer._train_step:
# day_index = (timestamp - global_min_timestamp) // 86400.  Computed once globally.
# raw_weight = exp(self.gamma_recency * day_index)
# weight = torch.clamp(raw_weight, min=0.5, max=2.0)
# loss = (per_sample_bce * weight).mean()
```

where `gamma_recency` is a `nn.Parameter(torch.tensor(0.0))` learnable scalar (init = 0 → weight = 1 for all → equivalent to I-670 at step 0). Gradient lets the optimizer learn whether recency emphasis helps.

Optional Phase 2 (if Phase 1 PROMOTE): add a second learnable `gamma_delay` using `delay_bucket = quantize(label_time - timestamp)`. Phase 2 introduces label_time as a sample-weight INPUT (still training-only, no inference dependence). DEFER to next session — Phase 1 first.
