# I-672 — MLDCN cross × MLPlatt calibration stack

## Hypothesis
Stack I-670's ML-DCN explicit cross branch with I-657's MLPlatt MonoCal calibration head. Two independently-PROMOTED orthogonal axes (架构 cross + 校准头) on the same I-643 base. Expected lift +0.0003~+0.0010 over I-670 SOTA (LB 0.825484).

## Base
- Fork from `experiments/I-670_mldcn_stable_cross/code/` (NEW SOTA, LB 0.825484)
- Inject I-657's `MLPlattCalibrationHead` per `experiments/I-657_mlplatt_monocal/IMPLEMENTATION_PLAN.md`

## Constraints (HARD, from CLAUDE.md + project docs)
- F2 id-leak: cross modules MUST NOT touch user_id / item_id learned embeddings (I-670 already complies; calibration head also must not)
- F3 loss-axis: keep BCE base loss; calibration is residual addition not reweighting
- Pattern B: this is NOT pattern B (calibration head adds NEW supervisory signal via residual cal_logit; not pure reweighting)
- α_cal = 0.25, α_mono = 0.05 (proven values from I-657 PROMOTE; do NOT change)
- Calibration head context: user_dense_feats ONLY (per I-657 audit; no item-derived fids)
- raw_logit.detach() before calibration head (per I-657 Codex A1 ruling)
- residual + zero-init final layer (per I-657 Codex A5 fix)
- separate grad-clip on base vs head params

## Architecture
PCVRHyFormer (I-670 with `MLDCNStableCross`) + new `MLPlattCalibrationHead`:
```
raw_logit = base_model(...)                # I-670 path: HyFormer + ML-DCN cross
cal_logit = raw_logit + MonoMLP([context_mlp(user_dense), raw_logit.detach()])
```
- Inference uses cal_logit if `--use_mlplatt`, else raw_logit
- Training joint loss: `L = BCE(raw_logit, y) + α_cal * BCE(cal_logit, y) + α_mono * mono_penalty(MonoMLP)`

## Files to modify (~150 lines total)
- `model.py`: add `MLPlattCalibrationHead` class (60 lines) + wire-up in `PCVRHyFormer.__init__` + forward returns tuple if head enabled (15 lines)
- `trainer.py`: add joint loss block (25 lines) + accept `--use_mlplatt`, `--mlplatt_alpha_cal`, `--mlplatt_alpha_mono` args (10 lines)
- `train.py`: argparse additions + pass to model_cfg + trainer (10 lines)
- `infer.py`: extract `cal_logit` if model returns tuple (6 lines) + **import `infer_eda_hook.probe_test_parquet` and call it after `test_dataset = PCVRParquetDataset(...)`** (3 lines)
- `run.sh`: env vars `USE_MLPLATT=1 MLPLATT_ALPHA_CAL=0.25 MLPLATT_ALPHA_MONO=0.05` (4 lines)
- Copy `infer_eda_hook.py` from `experiments/I-672_eda_probe/code/` to this dir

## Decision tree on LB
- ≥ 0.8265 → PROMOTE: 双 axis stack works, candidate for further stacking
- 0.8255-0.8264 → NEUTRAL: marginal stack gain, try α_cal=0.35 sweep
- 0.8245-0.8254 → calibration helped on I-643 but doesn't add on I-670 base
- < 0.8245 → KILL: stack interaction killed both gains, revisit
