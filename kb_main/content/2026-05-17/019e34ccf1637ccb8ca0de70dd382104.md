## Config delta vs baseline-0

```

```

That's it. **No timestamp_split, no id_dropout.** Single-variable capacity probe.

`dataset.py / train.py / model.py / trainer.py / utils.py / infer.py / ns_groups.json`
are byte-identical to baseline-0 pristine. Only `run.sh` carries the new flag.

## Why this experiment

I-604 is the **explore slot** paired with I-603 (exploit). Together they form an
orthogonal probe of the two main hypotheses for breaking past baseline-0:

| Probe | Hypothesis |
|---|---|
| I-603 (regularization) | "Model is overfitting; less reliance on long-tail IDs unlocks AUC" |
| I-604 (capacity) | "Model is under-parameterized; more depth lets it learn deeper interactions" |

baseline-0's epoch-by-epoch trajectory hints at potential capacity headroom:
best epoch was 6/11 (early-stopped at patience=5), suggesting the model was still
making progress when val plateaued. Whether that plateau is capacity-bound or
regularization-bound is exactly what this pair of experiments distinguishes.

## Why not NAL (G in initial Claude Code list)

Original Claude Code recommendation was G = NAL aux loss (DHEN paper +2.18%
prior, P estimated 0.30). Codex challenge in the discussion protocol pushed back:

1. **DHEN's NAL recipe is weight=0.0002 with 90pos/20neg sampling** — not the
   "add a head with weight=0.3" we'd ad-hoc. Implementation fidelity to the paper
   is non-trivial and one bug = 12h GPU wasted with un-diagnosable failure.
2. **Failure interpretability**: layer=3 failure tells us "capacity is not the
   bottleneck"; NAL failure could be wrong weight, wrong sampling, wrong target,
   or wrong mechanism — un-diagnosable.
3. **Local demo had NAL = -2.7%** (n=1000 noisy, but not zero evidence).

Consensus: **NAL deferred to I-605 with strict DHEN recipe**, not jammed into
I-604 as ad-hoc implementation.

## Mechanism

PCVRHyFormer with `num_hyformer_blocks=3` adds one more attention + FFN block on
top of the existing 2. Per-block parameters scale roughly linearly. With cold
restart's per-epoch sparse Embedding reset, the dense weights of the third
block must learn meaningful inter-token interactions despite the noisy
embedding stream — this is a genuine capacity test, not free model size.
