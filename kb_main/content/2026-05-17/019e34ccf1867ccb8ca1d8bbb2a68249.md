## Rationale

I-643 SOTA 0.824608 held against 5 stack attacks (-0.001 to -0.005). The
"add a feature" axis is locally saturated. Forum poster 杭仔 (whose UserPair
62-66 tip was directionally correct) reports replacing the transformer +
cross-attention seq encoder wholesale with DIN gives "提升很大" (~+0.005 by
implication, given top1=0.83 vs us 0.8246).

This experiment runs the **most conservative version of that signal** —
DIN on seq_a domain ONLY, with residual mean-pool fallback for OOV safety.
If this probe is +EV we expand to 4 domains (I-659); if KILL we close the
DIN axis without burning further quota.

## Why DIN doesn't replay the I-624/I-639 KILL pattern

| Mechanism | Output formula | OOV behavior |
|---|---|---|
| **I-624 token-mag gate** | `seq × sigmoid(MLP(target))` | target_emb random → output = seq × random_scalar → noise scaling |
| **I-639 feat gate** | `seq_time × sigmoid(MLP(target, ctx))` | same failure mode on time features |
| **I-658 DIN attention** | `Σ softmax(MLP([target, seq, target-seq, target*seq])) × seq` | target_emb random → attn weights random → output ≈ uniform mean-pool over seq (bounded, not noisy) |
| **I-658 DIN + residual fallback (v2)** | `α · DIN + (1-α) · masked_mean(seq)` | even if DIN attn is fully random, mean_pool path gives clean baseline |

Codex confirmed the OOV degradation is to mean-pool, not to noise. Residual
fallback adds a guarantee even if Codex's analysis is wrong.

## Design (v1 — post Codex challenge 2026-05-10)

### Replace scope
Replace MultiSeqQueryGenerator + MultiSeqHyFormerBlock × 2 + output_proj
**only on seq_a path**. Other 3 domains (seq_b, seq_c, seq_d) keep the
original transformer + cross-attention stack untouched. This is the
"single-domain probe" Codex demanded over full replacement.

### DIN module on seq_a

```
class DINAttentionPool(nn.Module):
    def __init__(self, d_model: int, hidden: int = 64, residual_alpha: float = 0.5):
        super().__init__()
        self.attn_mlp = nn.Sequential(
            nn.Linear(4 * d_model, hidden), nn.SiLU(),
            nn.Linear(hidden, 1),
        )
        self.alpha = residual_alpha  # weight on DIN; (1-alpha) on mean-pool

    def forward(self, target_q: torch.Tensor, seq: torch.Tensor,
                seq_pad_mask: torch.Tensor) -> torch.Tensor:
        # target_q: (B, D) — direct cate embedding from item_int_feats_84 (Codex A8)
        # seq: (B, L, D)
        # seq_pad_mask: (B, L), True = pad
        target_exp = target_q.unsqueeze(1).expand(-1, seq.shape[1], -1)
        din_inp = torch.cat([target_exp, seq,
                             target_exp - seq, target_exp * seq], dim=-1)  # (B, L, 4D)
        attn_logits = self.attn_mlp(din_inp).squeeze(-1)  # (B, L)
        attn_logits = attn_logits.masked_fill(seq_pad_mask, -1e9)  # Codex A9
        # Empty-sequence safety: if all positions padded, fallback to zero vector
        all_pad = seq_pad_mask.all(dim=-1, keepdim=True)  # (B, 1)
        attn_w = F.softmax(attn_logits, dim=-1)
        din_pool = (attn_w.unsqueeze(-1) * seq).sum(dim=1)  # (B, D)
        # Mean-pool fallback (Codex A1)
        valid = (~seq_pad_mask).float()
        seq_count = valid.sum(dim=-1, keepdim=True).clamp(min=1.0)
        mean_pool = (seq * valid.unsqueeze(-1)).sum(dim=1) / seq_count
        # Residual blend
        pooled = self.alpha * din_pool + (1 - self.alpha) * mean_pool
        # Zero out fully-padded rows entirely (Codex A9)
        pooled = pooled.masked_fill(all_pad, 0.0)
        return pooled
```

### Target construction (Codex A8 fix)

DO NOT use `item_ns.mean(dim=1)` — that averages RankMixer artificial chunks.
Instead, use **direct cate embedding lookup** from `item_int_feats_84`
(I-643's signal-rich cate field). New helper:

```python
# In model.py PCVRHyFormer.__init__:
self.din_target_cate_emb = nn.Embedding(
    num_embeddings=cate_vocab_size_84,  # ~67 on demo, <1000 on full
    embedding_dim=d_model,
)

# In forward:
cate_idx = inputs.item_int_feats[:, fid_pos_for_84]  # (B,)
din_target = self.din_target_cate_emb(cate_idx)  # (B, D)
```

This bypasses the RankMixer chunking artifact and gives DIN a clean
semantic-cate target (which is also OOV-safe — fid 84 has cardinality < 1000).

### Output_proj contract preservation (Codex A10)

The original `output_proj: nn.Linear(num_queries * num_sequences * d_model, d_model)`
expects (B, Nq * S * D). With DIN replacing seq_a, that slot is now
(B, D) (1 vector instead of Nq vectors).

**Solution**: pad DIN output by zero to (B, Nq * D) so output_proj input
shape stays unchanged. Or, replace output_proj with a wider Linear that
accepts both DIN slots and remaining transformer Q tokens.

For v1, **expand DIN output via repeat to Nq slots**:
```python
din_pool_a_expanded = din_pool_a.unsqueeze(1).expand(-1, num_queries, -1)
# Replace q_tokens_list[0] with this; output_proj sees same shape
```

This keeps output_proj / clsfier byte-identical → predict() return contract
preserved → infer.py needs no changes.

## Risk Audit

- **A1 OOV pattern A**: residual fallback + masked softmax + zero-row fallback for empty seq. Defense-in-depth.
- **A2 capacity**: only seq_a replaced; 3/4 of original capacity preserved.
- **A3 I-625 gap features**: gap-Fourier + dow-onehot still flow into seq_a tokens (`_embed_seq_domain` unchanged). DIN attention can learn "weight tokens by gap" via the `target × seq` term, though weaker than transformer self-attn on gap. Risk: -0.0011 partial loss of I-625 signal on seq_a; offset by DIN +EV.
- **A4 user-side info**: target = item-only (Codex A4 says test ablation; v1 uses item-only per forum, defer item+user to Probe 2 if v1 +EV).
- **A6 capacity addition**: DIN module ~5K params; new cate embedding ~67 × 64 = 4.3K params. Total ~9K added. Removing transformer-on-seq_a saves ~30K params per layer × 2 layers = 60K removed. Net -51K. Negligible vs total ~10M.
- **A8 target construction**: direct cate embedding lookup, NOT mean(item_ns chunks).
- **A9 padding mask**: explicit `masked_fill(-1e9)` before softmax + all-pad zero-row fallback.
- **A10 output contract**: shape-preserved via expand; predict() return unchanged.
- **NEW A11**: cate vocab embedding has its own gradient path → cold restart will reset it every epoch (it's a sparse Embedding by table heuristic). Verify whether `din_target_cate_emb` should be reset or kept persistent — if reset, DIN target signal collapses each epoch like I-635. **Decision pending Codex 2nd challenge**.

### A11 — cate embedding × cold restart: SELF-RESOLVED (b) keep persistent

**Code evidence** (`experiments/I-643_cate_oof_heat/code/model.py:1482-1541`):
the `reinit_high_cardinality_params` method only iterates two scopes:

```python
# scope 1: per-domain seq embeddings
for emb_list in [self._seq_embs[d] for d in self.seq_domains]:
    ...
# scope 2: NS tokenizer embeddings
for tokenizer in [self.user_ns_tokenizer, self.item_ns_tokenizer]:
    for emb in tokenizer.embs:
        ...
```

**It does NOT recurse over `self.modules()` or every `nn.Embedding` child**.
Therefore: if `din_target_cate_emb` is added as a top-level PCVRHyFormer
attribute (NOT inside `_seq_embs` / NOT inside any tokenizer), **it is
automatically skipped by reinit** at every epoch boundary. Weights persist.

Adagrad state interaction: trainer.py:412 rebuilds the sparse optimizer
each epoch, then at line 416-420 RESTORES state for params NOT in
`reinit_ptrs`. Since `din_target_cate_emb` is auto-skipped, its data_ptr is
not in `reinit_ptrs` → its Adagrad accumulators are restored → optimizer
state also persists across epochs.

**Net effect**: zero code change beyond making `din_target_cate_emb` a
top-level attribute. Persistent weights + persistent optimizer state, no
cold-restart conflict. v1 design is correct as-is.

### A12 — output_proj contract: SELF-RESOLVED (a) duplicate-expand

Rationale: option (b) rebuilds `output_proj` to `Linear((Nq*(S-1) + 1)*D, D)`,
which is structurally cleaner (1 slot for DIN, Nq*(S-1) slots for transformer)
but breaks shape compat with infer.py `_FALLBACK_MODEL_CFG`. Option (a)
duplicates DIN output across Nq slots so output_proj input shape stays at
`Nq*S*D`. The "wasted" duplicate slots are a minor capacity concern but
preserve checkpoint and infer-fallback compat. v1 design is correct.

### A13 — zero seq_a tokens: SELF-RESOLVED safe

`MultiSeqHyFormerBlock` (model.py:851+) has per-domain `seq_encoders[i]` and
`cross_attns[i]` — domain `i`'s Q only cross-attends to domain `i`'s
encoded seq. Zeroing seq_a's tokens means seq_encoder_a operates on zeros
(wasted compute, no harm) and cross_attn(DIN-Q, zeros) returns DIN-Q unchanged
(residual + zero-attention output). Cross-domain attention does NOT exist,
so seq_b/c/d's Q computation is unaffected. **Safe.**

Optimization for v2 (post-LB +EV): skip the seq_a encoder + cross_attn
entirely via a per-domain skip flag in MultiSeqHyFormerBlock to save compute.

### A14 — RankMixer × DIN item-conditioning compound risk: SELF-RESOLVED stay independent

I-643 already has `item_ns` (item-conditioned via tokenizer) feeding RankMixer.
DIN-derived Q for seq_a is also item-conditioned (via target attention).
**Two item-conditioned channels** but with **mechanistically different OOV
degradations**:
- `item_ns`: OOV item → random embedding lookup → noise injected at NS slot
- `DIN-Q`: OOV item → random target_q → random attention weights → output ≈
  mean-pool of seq_a (bounded, NOT noise)

The OOV failure modes are NOT correlated (one corrupts NS slot, other
gracefully degrades). RankMixer learns to weight them; no compounding
amplification expected. **Independent.**

### A15 — residual_alpha default: SELF-RESOLVED 0.5 for v1 probe

α=0.5 (equal blend DIN + mean-pool) is the conservative choice for the
first probe. If DIN signal is real (forum says +EV), 0.5 captures half;
if DIN is broken, 0.5 falls back to half-mean (still better than nothing).
α=0.7 (more aggressive) is reserved for v2 sweep IF v1 promotes.
