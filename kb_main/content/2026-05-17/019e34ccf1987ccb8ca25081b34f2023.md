# I-675 — Per-position AttnBias by action_type (2025 TAAC champion P0, isolated)

## Hypothesis

2025 TAAC 冠军的 Per-position Action Conditioning 三件套（FiLM + Gated Fusion + AttnBias）报告 +0.005~+0.015 AUC。**AttnBias 是其中实现量最小的一个**（核心改动只在 attention logits 加 bias），先单独测它的 isolated +EV。

并行 GPU-0 跑 I-674 (Ado-style)，**两个机制独立 isolate 归因**。stacks 不可加性 already 验证 (I-672 KILL = cross + calib stack)。

预期 lift +0.001~+0.003（冠军方案 +0.005~+0.015 是三件套合并；单 AttnBias 估算保守 1/3）。

## Base

Fork from `experiments/I-670_mldcn_stable_cross/code/` (current LB SOTA 0.825484).

**保留 I-670 的 ML-DCN cross 分支** — 已验证 +0.0005 PROMOTE。

|---|---|---|---|
| a | seq_41 | 9 unique [2-11] | ✅ |

## Architecture (change vs I-670 base)

### Stage 1: dataset.py 暴露 per-position action_type 到 batch

```python
# In _make_batch / __iter__
batch['action_type_a'] = torch.from_numpy(arr_seq_a_41)  # (B, T_a) int64, padding -1
batch['action_type_b'] = torch.from_numpy(arr_seq_b_68)
batch['action_type_c'] = torch.from_numpy(arr_seq_c_33)
batch['action_type_d'] = torch.from_numpy(arr_seq_d_17)
```

Padding 位置 (-1 or 0) → bias 取 0（不影响 attention）。

### Stage 2: HyFormer attention 加 AttnBias

```python
class ActionTypeAttnBias(nn.Module):
    """Per-position action_type bias added to attention logits (2025 TAAC P0)."""
    def __init__(self, n_action_types: int, n_heads: int):
        super().__init__()
        # init 0 → step 0 = baseline I-670 行为
        self.bias = nn.Parameter(torch.zeros(n_action_types, n_heads))
    
    def forward(self, attn_logits, action_per_pos):
        # attn_logits: (B, H, Lq, Lk)
        # action_per_pos: (B, Lk) int64, -1 = padding
        # 选 attention 的 key positions 的 bias
        valid = (action_per_pos >= 0).unsqueeze(-1)         # (B, Lk, 1)
        clamped = action_per_pos.clamp(min=0)               # padding 取 0 但下面会 mask 掉
        b = self.bias[clamped]                              # (B, Lk, H)
        b = b * valid.float()                               # padding 位置 bias=0
        b = b.permute(0, 2, 1).unsqueeze(2)                 # (B, H, 1, Lk) broadcast 到 Lq
        return attn_logits + b
```

每个 domain 一个 `ActionTypeAttnBias` 实例：
- domain_a: n_action_types=12 (clamp 范围 0-11), n_heads=4 → bias (12, 4)
- domain_b: 28, 4
- domain_c: 4, 4
- domain_d: 5, 4

集成到 HyFormer block 的 cross-attention 部分。每次 forward 把 action_type batch 张量传入，加到 attention logits 上。

## Decision tree on LB

- **PROMOTE ≥ +0.001**: AttnBias 在我们 schema 也 transfer；下一轮叠 FiLM (冠军另一件) 或 stack 进 I-676
- **PROMOTE +0.0005-+0.001**: 信号弱但有；考虑加 Gated Fusion (P0 第三件)
- **NEUTRAL ±0.0005**: 我们 action_type 字段语义跟冠军 schema 不一致；考虑换 domain 或 fid
- **KILL < -0.001**: AttnBias 在我们数据上有害；考虑跟 ML-DCN cross 互相干扰

## Why this passes "loss-axis closed" + "Pattern B" filters

- 不是 loss reweighting (Pattern B) — 是 attention 结构改造
- AttnBias 是 **新参数 + 新 supervision signal**（per-position action_type 之前从未进入 model）
- 跟 "valid AUC ≠ LB" 铁律不冲突 — 这是 inference-path 结构改造，influence 是模型自身行为
