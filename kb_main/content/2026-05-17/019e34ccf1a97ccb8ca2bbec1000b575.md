# External Research — Gate A v2.1 (Post-MC-MLCC Pivot)

## Search Angles (used)

- **Angle 1 (Recommended)**: DCNv2/v3 + FM-family explicit cross over **STABLE ATTRIBUTE features only** (anonymized integer demographic/category groups, dense float embeddings, context features) — NOT crossing user_id or item_id. ≥2025. Single-model. Latency-aware.
- **Angle 2**: 2025+ regularization techniques for CTR/CVR with distribution-shift validation. ≥2025.

## Verified Findings — Angle 1

### 1. DCN^2: Interplay of Implicit Collision Weights and Explicit Cross Layers for Large-Scale Recommendation

- **Authors**: Blaž Škrlj, Yonatan Karni, Grega Gašperšič, et al.
- **Year / venue**: 2025, AdKDD 25
- **URL**: https://arxiv.org/abs/2506.21624
- **Verification**: PASS (title + year + authors all match)
- **Finding**: Three algorithmic improvements to DCNv2 architecture, validated offline + in online A/B tests at high prediction volume. Production-scale baseline upgrades.
- **Compliance flags**: Codex marked `[borderline: paper's full system includes learnable lookup/collision mechanisms over sparse IDs; those parts must be REJECTED under F2 (id-dep failure mode)]`. **Port the explicit-cross-layer / pairwise-similarity parts; exclude collision-weight lookup over uid/item_id.**

### 2. ML-DCN: Masked Low-Rank Deep Crossing Network Towards Scalable Ads CTR Prediction at Pinterest

- **Authors**: Jiacheng Li, Yixiong Meng, Yi Wu, et al.
- **Year / venue**: 2026, arXiv
- **URL**: https://arxiv.org/abs/2602.09194
- **Verification**: PASS
- **Finding**: At Pinterest production scale, naive DCNv2/MaskNet scaling has diminishing returns under fixed FLOPs/latency. Introduces a **masked low-rank crossing layer** that improves AUC at matched FLOPs, deployed with neutral serving cost.
- **Compliance flags**: Codex marked `[borderline: instance-conditioned masking resembles gating. NOT the closed token-mag/time/temporal-decay gating, but should be implemented as a lightweight cross-feature SELECTOR (not a multiplicative gate on token activations).]` This is the architecturally closest to our latency-constrained setting.

### 3. DLF: Enhancing Explicit-Implicit Interaction via Dynamic Low-Order-Aware Fusion for CTR Prediction

- **Authors**: Kefan Wang, Hao Wang, Wei Guo, et al.
- **Year / venue**: 2025, SIGIR 25
- **URL**: https://arxiv.org/abs/2505.19182
- **Verification**: PASS
- **Finding**: Combines **explicit low-order interaction preservation** with implicit nonlinear modeling via Residual-Aware Low-Order Interaction Network + dynamic fusion. Improves public CTR benchmark AUC over feature-interaction baselines.
- **Compliance flags**: Codex marked `[borderline: fusion module is dynamic and attention-like. Keep shallow OR replace with static/residual fusion if latency or gating-risk surfaces.]`

### 4. From Scaling to Structured Expressivity: Rethinking Transformers for CTR Prediction

- **Authors**: Bencheng Yan, Yuejie Lei, Zhiyuan Zeng, et al.
- **Year / venue**: 2025, arXiv
- **URL**: https://arxiv.org/abs/2511.12081
- **Verification**: PASS
- **Finding**: Argues unstructured attention is **misaligned with CTR data** because CTR needs combinatorial reasoning over semantic fields, not sequence-like token composition. Proposes **Field-Aware Transformer** that injects field-level interaction priors into attention; +0.51% AUC + online CTR/RPM gains.
- **Compliance flags**: Codex marked `[borderline: NOT DCN/FM-family per se. Include as SUPPORTING EVIDENCE for field-aware structured cross design, NOT as a primary architecture transplant.]`

## Angle 2 — Effectively Dry (Honest Reporting)

Codex search returned **<2 verified papers** that satisfy all hard constraints for Angle 2. Explicit rejection reasons:
- Not CTR/CVR-specific
- Not tested under severe train/test distribution shift
- Relied on id-dependent SSL/pretraining (F2 violation)
- Optimized loss-axis objectives (F3 / A4 violation)
- Pre-2025

**Closest non-returned candidates**:
- "A Probabilistic Framework for Temporal Distribution Generalization in Industry-Scale Recommender Systems" (2025) — industrial-shift-focused but has self-supervised / id-representation risk

**Implication**: The classic regularization tools (SAM, SWA, R-Drop, mixup, label smoothing v2) are well-known but lack 2025 peer-reviewed CTR/CVR papers with verified severe-distribution-shift testing. They can still be tried IN OUR PROJECT — but without paper-grounded confidence. Each variant would be a "shoot from the hip" experiment.

## Cross-Paper Synthesis

All 4 Angle-1 papers converge on the same architectural prior:

> **Explicit field-aware cross-feature interaction modules outperform attention-only or implicit-only architectures on industrial CTR/CVR data with anonymized categorical + dense features.**

Concrete design family from the papers:
- DCNv2-style explicit polynomial cross over field embeddings (DCN^2)
- Low-rank cross under FLOPs budget (ML-DCN)
- Explicit-implicit dual-branch with residual low-order preservation (DLF)
- Field-aware attention prior (Field-Aware Transformer)

**Common constraint**: all 4 must be ported with strict "no uid/item_id cross / lookup / collision-weighting" filter — the parts that DEPEND on learned id embeddings recreate F2.
