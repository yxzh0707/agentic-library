# I-672 — MLDCN Stable Cross × MLPlatt Calibration

## Design

Forked from `experiments/I-670_mldcn_stable_cross/code/` (LB 0.825484) and adds a residual MLPlatt calibration head on top of the raw ML-DCN-enhanced logit. The base forward path remains the I-670 HyFormer + stable-attribute ML-DCN cross branch; the calibration head consumes only `user_dense_feats` plus a detached raw logit.

## Training Objective

`L = BCE(raw_logit, y) + 0.25 * BCE(cal_logit, y) + 0.05 * mono_penalty`

The calibration branch detaches `raw_logit` before the head so calibration loss cannot directly contaminate the base logit graph. The monotonicity penalty is computed from the calibrated logit slope with respect to the detached raw logit.

## Safety Constraints

- No user_id/item_id learned embedding changes.
- Calibration context is user dense features only; item features are excluded.
- Final MLPlatt residual layer is zero-initialized, making step-0 behavior identical to I-670.
- Base and calibration-head gradients are clipped separately.
- Inference uses calibrated logits when the head is enabled.
- `infer_eda_hook.probe_test_parquet(data_dir)` runs after test dataset construction to log test timestamp/delay distribution.
