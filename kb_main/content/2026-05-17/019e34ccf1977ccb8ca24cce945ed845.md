# I-674 — Ado-style ue separation + stat path + int-pair weighting (no 89-91)

## Hypothesis

论坛上多个用户反馈 Ado 路线涨分。Step 1 (user_dense 三路拆 + int-pair 加权 + 89-91 剔除) 对应 SPHINX V7.6 的 DenseGroupProjector 设计。**预期 lift +0.002~+0.005**（外部验证）。

并行 GPU-1 跑 I-675 (AttnBias 独立)，二者机制不混在一个实验，便于 isolate +EV 归因。

## Base

Fork from `experiments/I-670_mldcn_stable_cross/code/` (current LB SOTA 0.825484).

**保留 I-670 的 ML-DCN cross 分支** — 已验证 +0.0005 PROMOTE，不去掉。

### Stage 2: 模型 forward (model.py)

```python
class AdoDensePaths(nn.Module):
    """Three-path user_dense encoder: ue / stat → emb / int-pair gate."""
    def __init__(self, ue_in=576, stat_in=17, d_emb=64, user_int_dim=...):
        super().__init__()
        self.ue_proj = nn.Linear(ue_in, d_emb)
        self.stat_proj = nn.Sequential(
            nn.Linear(stat_in, 32), nn.SiLU(),
            nn.Linear(32, d_emb),
        )
        # int-pair gate: stat_emb → gating scalar per user_int token
        self.int_pair_gate = nn.Linear(d_emb, user_int_n_tokens)   # n_tokens ≈ 4
        # γ scalar for residual write-back (init 0)
        self.gamma_dense = nn.Parameter(torch.tensor(0.0))
    
    def forward(self, ue_dense, stat_dense, user_int_tokens):
        ue_emb = self.ue_proj(ue_dense)                # (B, d_emb)
        stat_emb = self.stat_proj(stat_dense)          # (B, d_emb)
        # Gate user_int tokens by stat signal
        gate = torch.sigmoid(self.int_pair_gate(stat_emb))  # (B, n_tokens) ∈ [0,1]
        # Apply gate element-wise: user_int[i] *= (1 + γ * (gate[i] - 0.5))
        gated_user_int = user_int_tokens * (1 + self.gamma_dense * (gate.unsqueeze(-1) - 0.5))
        return ue_emb, stat_emb, gated_user_int
```

集成到 `PCVRHyFormer.forward()`：
- `ue_emb` 作为额外 NS token concat 进 user-side
- `stat_emb` 作为额外 NS token concat 进 user-side
- `gated_user_int` 替代原本的 user_int NS token batch

γ_dense init = 0 → step 0 时 gate effective = 1.0 (no change) → 模型行为接近 I-670 baseline。学习驱动 gate 凸显。

## Decision tree on LB

- **PROMOTE ≥ +0.001 (Top 50 hopeful)**: 验证 Ado 路线在我们 schema 也涨；下一轮叠 SPHINX Sharpened Routing
- **PROMOTE +0.0005-0.001**: 信号弱但有；考虑同时叠 stat→quantile 路（带回 89-91）
