id: I-665

prior:
  source: "arXiv 2602.12041 MC-MLCC (Bilibili 2026)"
  expected_lb_auc: 0.826
  range: [0.823, 0.828]
  baseline_lb_auc: 0.824608  # I-643 SOTA
  expected_delta: +0.0012  # Bilibili industrial Table 4 vs RankMixer
  rationale: |
    MC-MLCC Bilibili Table 4: RankMixer 0.8322 -> MC-MLCC 0.8334 (+0.0012,
    57x fewer params). Our PCVRHyFormer uses RankMixer-style NS tokenizer
    so this delta is directly addressable.
  p_improve_over_baseline: 0.55  # moderate confidence single-paper finding
  p_kill_under_0822: 0.20

rationale:
  - Architecture axis on top of I-643 has not been seriously tried.
    Closed axes: seq replacement (DIN), loss reweight (4/4), gating (3/3),
    time-feature stack (4/4). Cross-feature compressor is structurally
    DIFFERENT from those — it operates on dense post-attention features,
    not input gates or seq tokens.
  - Passes data_understanding_v2 dual-condition:
      (a) NEW signal: heterogeneous low-rank feature cross interactions
          (currently I-643 only has linear output_proj after attention).
      (b) OOV-safe: operates on d_model dense space, NOT bound to
          item_id or any sparse vocab.
      (c) BONUS — training-dynamic axis: compressor learns rank-r
          interactions during training (new optimization signal).

design:
  injection_point: |
    Between output_proj (model.py line 1647) and clsfier (line 1693).
    Currently:
      output = self.output_proj(all_q.view(B, -1))  # (B, D=64)
      logits = self.clsfier(output)
    
    New:
      output = self.output_proj(all_q.view(B, -1))  # (B, D=64)
      output = output + gamma * self.local_compressor(output)  # residual
      logits = self.clsfier(output)

  local_compressor_spec: |
    # Per arXiv 2602.12041 Sec 3.3 + Table 5 rank ablation.
    # Input/output: (B, D=64). Block-wise low-rank cross with rank E'=8.
    # Paper Table 5: E'=8 r=4 -> 0.8301 AUC, 9.8M params, 40.7 GFLOPs;
    # within 0.0002 of full E'=32. We pick rank=8 not 16 to limit
    # overfit on our 4M-row train set (vs paper 10B+ industrial rows).
    
    K = 4  # number of blocks
    block_dim = D // K  # = 16
    E_prime = 8  # compressed rank
    
    For each block k in [0, K-1]:
      block_in = output[:, k*block_dim : (k+1)*block_dim]  # (B, 16)
      compressed = block_in @ W_compress[k]  # (B, 16) @ (16, 8) = (B, 8)
      crossed = compressed * compressed  # element-wise square
      block_out = crossed @ W_expand[k]  # (B, 8) @ (8, 16) = (B, 16)
    
    output_cross = concat(block_outs, dim=-1)  # (B, D=64)
    Final: output = output + gamma * output_cross  # gamma=0.0 init, learnable
  
  new_dense_params: |
    Per block: W_compress (16x8=128) + W_expand (8x16=128) = 256 params
    K=4 blocks * 256 = 1024 params + gamma scalar = 1025 total
    vs I-643 ~2.5M = +0.04%. Negligible capacity addition — change is
    qualitative (cross interaction), not capacity scaling.
