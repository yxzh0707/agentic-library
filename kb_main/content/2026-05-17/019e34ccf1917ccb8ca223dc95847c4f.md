# I-675 — Per-Position Action-Type Attention Bias

Forks `experiments/I-670_mldcn_stable_cross/code/` (LB SOTA 0.825484) and keeps the I-670 ML-DCN stable cross branch.

## Design

- Exposes per-position action-type tensors from sequence side-info:
  - `action_type_a`: `domain_a_seq_41`, clamped to `[0, 11]`, padding `-1`.
  - `action_type_b`: `domain_b_seq_68`, clamped to `[0, 27]`, padding `-1`.
  - `action_type_c`: `domain_c_seq_33`, clamped to `[0, 3]`, padding `-1`.
  - `action_type_d`: `domain_d_seq_17`, clamped to `[0, 4]`, padding `-1`.
- Adds one `ActionTypeAttnBias` module per sequence domain.
- Adds the learned per-action bias to cross-attention logits before softmax.
- Initializes all action-bias parameters to zero, so step-0 behavior matches I-670.
- Monitors validation logloss with `EarlyStopping(direction='min')`.

## Safety Constraints

- Does not add or modify `user_id` / `item_id` learned embeddings.
- Keeps the ML-DCN cross branch in place.
- Bias parameters are zero-initialized for baseline-equivalent startup.
