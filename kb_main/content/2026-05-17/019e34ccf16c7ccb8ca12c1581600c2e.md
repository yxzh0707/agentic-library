## Why this is a placeholder, not yet built

I-626 measures **chemistry between individually +EV time features**. Building it before knowing
which features ARE +EV is wasted work — could become "I-625 + nothing" if both individuals KILL,
or just I-616 v2 if only hour wins (which would be redundant rebuild).

1. **过去的 stack 已经在 I-625 里隐式完成**：I-625 = baseline + Fourier + recency + bucket + gap，
   这是 4 个时间特征的 sequential stack。LB 0.822863 = 这个 stack 的总效应。
2. **未来的并发 stack 在 I-626 等待触发**——条件是个体 +EV 验证完毕。
3. **I-615 v2 KILL 已经验证化学风险真实存在**（耦合频率扫毁 gap 信号）。所以
   stack 实验本身要打 LB 验证，不能假设 sum(individual_gains) 就是 stack_gain。
