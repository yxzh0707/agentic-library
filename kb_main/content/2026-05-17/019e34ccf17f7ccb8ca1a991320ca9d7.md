# I-654_cate_oof_dow_stack

```yaml
id: I-654
name: cate_oof_dow_stack
status: ready_for_taiji
base: experiments/I-643_cate_oof_heat/code/
fork_base: "experiments/I-643_cate_oof_heat/code/"
stack_components:
  - I-643 cate-level OOF heat on item_int_feats_84
  - I-617 day-of-week onehot sequence time feature
baseline_lb_auc:
  I-625: 0.822863
  I-617: 0.823511
  I-643: 0.824608
prior:
  expected_lb_auc: 0.8250
  range: [0.8230, 0.8265]
  p_improve_over_I643: 0.35
```

## Rationale

I-643 is the current best single model line (`0.824608`) and adds an
OOV-safer item-side cate signal. I-617 independently showed day-of-week can
transfer (`0.823511`) with a tiny 7-dim sequence-time addition.

I-654 tests the cleanest orthogonal stack:

- item-side: cate OOF heat, inherited from I-643;
- time-side: per-token day-of-week onehot, inherited from I-617;
- no new gates, no attention changes, no loss change.

## Changes vs I-643

- `dataset.py`
  - adds `DOW_ONEHOT_DIM = 7`;
  - changes `SEQ_TIME_FEAT_DIM` from `24` to `31`;
  - appends day-of-week onehot after the existing 8-dim gap Fourier block.
- `model.py`
  - updates fallback `seq_time_feat_dim` default to `31`.
- `train.py` / `infer.py`
  - continue to derive `seq_time_feat_dim` from `dataset.SEQ_TIME_FEAT_DIM`.
- `run.sh`
  - keeps I-643 active config: `rankmixer`, `user_ns_tokens=4`,
    `item_ns_tokens=2`, `item_heat_alpha=100.0`;
  - adds I-654 identity in logs/comments.

## Risk Audit

- Positive path: I-643 and I-617 signals are orthogonal enough to stack.
- Main risk: day-of-week consumes small capacity but does not add marginal
  signal once cate heat is present.
- Attribution risk is low because only one new axis is added to I-643.

## Decision Thresholds

- promote if `leaderboard_auc >= 0.8250`;
- neutral if `0.8240 <= leaderboard_auc < 0.8250`;
- kill if `< 0.8240`.
