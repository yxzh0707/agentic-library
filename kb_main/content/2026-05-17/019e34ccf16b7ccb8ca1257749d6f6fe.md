## Notes

8 new dense dims per token, projected through the existing Linear(seq_time_feat_dim, d_model).
Parameter increase: 4 domains × (8*64 + 64) = 2304 new params (from the wider projection).
No new modules — the Linear layer's input dimension grows from 16 to 24.

The gap computation uses abs() because all sequences are reverse-chronological.
Without abs(), gaps would be negative (e.g., ts[1]=80, ts[0]=100 → gap = -20),
which would produce meaningless Fourier phases.
