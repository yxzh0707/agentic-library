## Notes

**Sanity test pass (6/6)**:
1. ✅ Normal case (5% pos, 85% click, 10% other): finite loss
2. ✅ No positives → BCE-only fallback
3. ✅ No hard negatives → BCE-only fallback
4. ✅ λ=0 exactly equals BCE (0.839963 vs 0.839963)
5. ✅ Gradient finite, non-zero
6. ✅ Direction correctness: bad ranking (2.4946) > good ranking (0.3063)

**Implementation choices**:
- All-pair outer broadcast: `pair_diff[i, j] = neg_logit[j] - pos_logit[i]`
  - For batch=256 with ~5% pos / 85% click, ~13×218 = 2.8K pairs/batch
  - PyTorch vectorized, ~negligible overhead
- Softplus instead of explicit log(1+exp): numerical stability
- Edge case fallback to BCE: prevents NaN on degenerate batches

**Lambda choice**:
- 0.3 = midpoint of [0.1, 0.5] PWiseR paper recommendation
- 跑出来 + sweep 是 next step

**对照 I-630 (focal α=0.25 KILL 0.81710)**:
- I-630: pointwise reweighting, mechanism mismatch
- I-632: pairwise hard-pair, mechanism is direct AUC optimization
