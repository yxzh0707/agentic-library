# TAAC 2026 Competition Analysis

## Problem
Predict CVR from unified model handling sequential + non-sequential features.

## Architecture Approaches
1. **HSTU** (Meta baseline): Pointwise normalization, O(n) complexity
2. **OneTrans** (ByteDance): Unified Transformer for sequence + feature interaction
3. **HyFormer** (ByteDance): Alternating Query Decoding and Boosting

## Key Insight
Core challenge is feature heterogeneity, not backbone selection. Recommended: HSTU baseline with OneTrans-style feature interaction blocks.
