# MCP (Model Context Protocol)

MCP 是 Anthropic 提出的标准协议，用于 LLM 与外部工具和数据的通信。

核心概念：
- Server: 提供工具和资源的服务端
- Client: 消费工具和资源的客户端
- Transport: 协议传输层（stdio/HTTP）
- Tool: 可被 LLM 调用的函数
- Resource: 可被 LLM 读取的数据

Hermes Agent 内置原生 MCP 客户端支持。
