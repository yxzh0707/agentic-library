# 综合 framing：从这堆资料里得到的可行动态作战计划

## 赛题已知事实（不再赘述）
- 单一同构 backbone + 可堆叠统一 block
- 输出 pCVR，AUC + 延迟双约束
- 禁 ensemble
- 两个论文奖：Unified Block Innovation / Scaling Law Innovation

## 资料给出的"可选动作清单"

### A. Backbone 类型（选一个作为主线）
| 选择 | 主要论文 | 优势 | 劣势 |
|---|---|---|---|
| HSTU | 2402.17152 | 5-15x 比标准 Transformer 快、有 scaling law | 没显式 NS 区分 |
| OneTrans (基于 MHA) | 2510.26104 | 赛题官方推荐、NS 独占参数 | attention 复杂度高、靠 KV cache 救延迟 |
| HyFormer (Query Decoding) | 2601.12681 | 长序列天然压缩、双向信息流 | 实现复杂、调参面大 |
| MTGR (HSTU + GLN) | 2505.18654 | HSTU 工业化版、保留 cross feature | 增量较小，论文价值弱 |

**首选**：MTGR (HSTU+GLN+dynamic mask)。理由：起步代价最低、保留赛题数据里 cross feature 的语义、有工业 baseline 数字。

### B. Tokenizer 设计
**序列侧**：4 域 timestamp-aware interleave，每事件 = item_id emb + action_type emb + time_bucket emb（拼接而非 baseline 的加法），加 4 维 domain type embedding。

**非序列侧**：group-wise (OneTrans 风)，三组：
- user 组：46 个 user_int_feats + 10 个 user_dense_feats → 8-16 个 user token
- item 组：14 个 item_int_feats → 4-8 个 item token
- candidate 组：当前打分的目标广告 → 1 个 candidate token

### C. Block 内部结构
- Spatial aggregation 用 HSTU 的 pointwise normalization（拿到延迟优势）
- Layer normalization 按语义分组（MTGR 的 GLN）
- 参数规则：序列 token 共享、NS token 独占（借 OneTrans）
- Mask：dynamic mask 隔离不该互看的 token（MTGR）

### D. 训练目标
主 loss：CVR BCE
辅助 loss：Next Action Prediction（TransAct V2）—— 序列侧自监督，inference 时不开
辅助 loss：CTR BCE（OneTrans 路径同时多任务）

### E. 延迟优化（从训练就要锁定）
- 训练即 causal attention，推理才能开 cross-request KV cache
- FlashAttention-2 + BF16 混合精度
- 序列侧两阶段：per-request 一次序列前向 → per-candidate 只算 NS

### F. Scaling Law 实验
跑三档模型（小/中/大），扫 W、D、token 数三维度，画 (FLOPs, AUC) 曲线。这是 Scaling Law Innovation Award 的论文骨架。

## 不确定项（需要先验证再做架构决策）
1. 单 sample 序列长度分布（决定要不要 GSU 风检索）
2. 实际延迟预算具体数值（赛题文档没给精确值）
3. 4 个 domain 的事件量比例（决定 type embedding 该怎么设计）
4. Cross feature (10 列 user_dense_feats) 的物理含义和数值范围（决定 dense 投影策略）

## 提交策略（赛题禁 ensemble）
- 单模型：MTGR-style backbone + group-wise NS tokenizer + KV cache
- 但训练阶段可以做 distillation：训一个大 OneTrans 老师 → 蒸到一个能在延迟内的 MTGR 学生。蒸馏不是 ensemble。

## 论文奖项 framing
- **Unified Block Innovation Award**：组合贡献 = MTGR 的 GLN + OneTrans 的参数分化 + HyFormer 的 Query Decoding 作为层间池化算子。三者交叉处。
- **Scaling Law Innovation Award**：在赛题数据上跑出 (FLOPs, AUC) 双对数曲线，重点是 NS token 数量 T 这个新维度的 scaling 行为（前人都只 scale W 和 D）。

## 阅读优先级（如果要逐字精读）
1. OneTrans (2510.26104) — 赛题官方推荐
2. HSTU (2402.17152) — baseline 用的
3. MTGR (2505.18654) — 最实用的工程参考
4. HyFormer (2601.12681) — 最新对手

6. TransAct V2 (2506.02267) — 长序列辅助 loss
