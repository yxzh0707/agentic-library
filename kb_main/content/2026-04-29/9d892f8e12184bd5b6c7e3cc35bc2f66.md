# 赛题列出的经典 baseline（DIN / DIEN / DCN / DCNv2 / SASRec / BERT4Rec）

赛题文档明确把这些列在"分裂的两条路线"里。投稿要在论文里引用它们做对照——但更重要的是，**这些经典里有些 trick 可以被吸收进统一 backbone**。

## 序列侧三块基石

### DIN — Deep Interest Network (Alibaba 2017)
> arxiv 1706.06978

- **核心 trick**：local activation unit / **target attention**
- 经典做法是把用户行为序列 mean-pool 成定长向量，DIN 改成"用候选 ad 做 query，对历史行为做 weighted sum"，让用户表示**因 ad 而异**
- 工业部署：阿里展示广告主流量，2B 样本

**赛题里怎么吸收**：
- 在 unified token 流里，candidate ad token 必须能 attend 历史行为 token
- baseline 的 [CLS, User, Item, Sequence] 默认 CLS 做最终预测——但**让 candidate ad token 自己做最终预测，并对序列做 target attention，等价于在 unified 框架里复活 DIN 的核心**
- 这是赛题里"尊重经典"的最小但有效改动

### DIEN — Deep Interest Evolution Network (Alibaba 2018)
- DIN 的升级：用 GRU + auxiliary loss 显式建模兴趣演化
- **赛题里怎么吸收**：DIEN 的 auxiliary loss（预测下一行为）跟 TransAct V2 的 Next Action Loss 是同一思路。在 unified backbone 里这是廉价的辅助 loss

### SASRec — Self-Attentive Sequential Recommendation (UCSD 2018)
> arxiv 1808.09781

- **核心**：第一篇把 Transformer self-attention 用于序列推荐的论文。Causal mask + last token 做预测
- 比 RNN 快一个数量级
- 后续所有 sequential recommender（HSTU 包括）都建立在这之上

### BERT4Rec — Bidirectional Encoder (2019)
> arxiv 1904.06690

- SASRec 的 bidirectional 版：Cloze 任务（masked LM）
- 数据集依赖严重，整体跟 SASRec 各占胜场（SASRec 24%, BERT4Rec 64%, tie 12%）

**赛题里怎么吸收**：
- SASRec 的 causal mask 跟 OneTrans 一致——可以直接 reuse
- BERT4Rec 的 Cloze 在赛题里**不能直接做**因为是预测 CVR 不是预测 next item，但 mask language modeling 可作为 pretrain 阶段
- 一种可能：先在序列上 BERT4Rec 风预训练 backbone，再 fine-tune 到 CVR——但赛题禁 ensemble，要确认这种 staged training 算不算违规

## 非序列侧两块基石

### DCN — Deep & Cross Network (Google 2017)
- **核心**：cross network 显式建模任意阶特征交叉，每层做 (x_0 ⊗ x_l) + x_l 的线性递推
- 比 FM 表达力强，比 DNN 收敛快

### DCN-V2 (Google 2020)
> arxiv 2008.13535

- 把 cross network 中的 vector 形式升级为 **matrix 形式**（参数从 O(d) 变 O(d²)，但用低秩分解控制）
- mixture of low-rank cross layers 是工业部署的主力
- Google 大规模部署，多个产品线 AUC 提升

**赛题里怎么吸收**：
- OneTrans 跟 DCN-V2 + DIN 比 +1.53% AUC——说明 DCN-V2 是当前最强的 NS 侧 baseline
- 在 unified block 里，**NS token 之间的 cross attention 可以视为 DCN-V2 的 generalization**——cross network 是 fixed kernel 的特征交叉，attention 是 learned kernel 的特征交叉
- 想拿 Unified Block Innovation Award 可以从这个角度切入：**证明 unified attention 在 NS 侧的表达力等价或超过 DCN-V2**

## 这一组经典在论文里的位置
- 论文 Section 2 (Related Work) 必须引用这些
- 论文 Section 4 (Experiments) 把 baseline 表打全：DIN+DCNv2 / DIN+DCN / SASRec / BERT4Rec / 然后是同时代 unified 模型（OneTrans/HyFormer）
- 这个 baseline 表是审稿人会看的第一件事

## 一句话 framing
**经典模型在赛题里不是被"打败"的对象，而是 unified backbone 必须能"包含"的能力**。如果你的统一 block 在足够窄/浅的极限下退化成 DIN 或 DCNv2，那是好事，是评审会给"洞察力"分的点。
