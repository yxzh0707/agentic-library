# 上届 TAAC 2025 + 生成式推荐 tokenization（与本届赛题的关系）

## 上届 TAAC 2025 是什么主题
- 名字：Tencent Advertising Algorithm Challenge 2025: **All-Modality Generative Recommendation**
- arxiv 总结论文：2604.04976
- 数据集：TencentGR-1M（百万用户，每人 ≤100 交互）+ TencentGR-10M（千万用户，明确区分 click 和 conversion）
- 参赛规模：8400+ 注册，2800+ 队伍

## 上届与本届的关键区别

| 维度 | TAAC 2025 | TAAC 2026 (本届) |
|---|---|---|
| 任务范式 | 生成式（auto-regressive 预测下一 item） | 判别式（pCVR） |
| 模态 | All-modality（文本、图像、行为）| 匿名 int/dense 字段 + 行为序列 |
| 主指标 | 生成质量 + 业务指标加权 | ROC-AUC |
| 架构期待 | LLM 风 backbone + tokenizer | 单一同构主干 + 统一 block |

但核心连续性：**两届都在推"统一 backbone"**——上届走生成式 LLM 路线，本届走 unified token + 判别式路线。**上届顶级方案的 tokenizer 经验是直接可借的**。

## 上届冠军方案的 framing
- 用 dense Qwen backbone 做 multi-modal auto-regressive
- 关键工程点：**冷启动**、**filter bubble**、**modality fragmentation**

虽然本届用不上 multi-modal，但"modality fragmentation"思路对应到本届就是"序列特征 vs 非序列特征 fragmentation"——同一个问题的不同 instance。

## 生成式推荐的 Tokenization 体系（与本届赛题最相关的部分）

赛题 Unified Block Innovation 奖项里如果想做 token 化层的创新，必须了解下面这套体系：

### TIGER + RQ-VAE — 把 item 编成离散 semantic ID
- 论文：Recommender Systems with Generative Retrieval (NeurIPS 2023)
- 思路：用 LLM/T5 编码器把 item 内容特征编成 dense embedding → 用 **Residual-Quantized VAE (RQ-VAE)** 做多级量化 → 得到 (c1, c2, c3, c4) 这种 tuple 形式的 semantic ID
- 优势：相似 item 共享前缀（c1 一致），冷启动友好；离散 ID 可被 Transformer 像 NLP 的 token 一样建模

### Semantic ID 在 ranking 里的应用
- "Better Generalization with Semantic IDs: A Case Study in Ranking" (arxiv 2306.08121)
- 把传统 hash bucket ID 替换成 semantic ID，relevance ranking 显著提升
- "Enhancing Embedding Representation Stability with Semantic ID" (2504.02137) — 解决 hash collision 不稳定

### Hierarchical Semantic ID
- HiD-VAE (2508.04618) — 可解释 + 层次化
- "Adaptive Semantic Tokenization" (2511.08006) — 跨域生成式推荐

## 本届赛题怎么借这条线

### 借法 A — 直接把 item_id 替换成 semantic ID
- 赛题数据是匿名 int 字典，但 item_id 仍然是高基数（百万级）
- 用 RQ-VAE 把 item_id 的协同 embedding（从行为共现学）量化成 4-tuple
- 输入 backbone 的不再是单一 item_id 而是 [c1, c2, c3, c4] 四个 token
- **延迟代价**：单 item 占 4 个 token，但允许跨 item 参数共享，整体不一定变贵

### 借法 B — semantic ID 作为冷启动备选
- 主分支用 hash bucket embedding
- 冷启动 item（出现次数 < 阈值）用 RQ-VAE 学到的 semantic ID embedding
- 适合赛题的 long-tail item 场景

### 借法 C — 用 GPR (2511.10138) 的"unified semantic ID 空间"思路
- 把 ads 和 organic content 都映射到同一 semantic ID 空间
- 赛题里对应"广告 item"和"序列里的 item"统一编码
- 减少 embedding 总参数

## 风险提示
- RQ-VAE 训练本身需要 item content feature（文本/图像），赛题数据是匿名 int，没有原始内容
- 解决方法：用行为共现矩阵做协同编码，把 RQ-VAE 训练在协同 embedding 上而非内容 embedding 上
- 这是个**具体实验值得做**：先训一个 SASRec/BERT4Rec 拿到 item embedding，然后 RQ-VAE 量化，再喂回主模型
