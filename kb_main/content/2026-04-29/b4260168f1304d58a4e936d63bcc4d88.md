# HiFormer / InterFormer — 异构特征 + 双向交互的另两条路

## HiFormer — 异构 self-attention + 低秩近似 + 剪枝

> arxiv 2311.05884

核心：**修改 self-attention 接受异构特征**——不同 feature group 之间 attention 不同 weight matrix。然后用低秩近似 + 剪枝把模型压小到能上线。

赛题映射：HiFormer 把 self-attention 改成异构形式，跟 OneTrans 的 NS 独占参数是同一类思路，但 HiFormer 来得更早。OneTrans 可以视为 HiFormer 思路在赛题官方推荐路径上的现代化重写。

**实用价值**：HiFormer 给出了"低秩近似 + 模型剪枝"做 fast inference 的具体方法。这是赛题延迟约束下不可忽略的工程线。

## InterFormer — 在序列层和交互层之间塞 learnable interaction tokens

核心：**learnable interaction tokens** 同时连接 sequence encoder 和 feature interaction network，让信号双向交换。InterFormer 把 feature interaction layer 和 sequence layer **交错堆叠**。

赛题映射：交错堆叠这个想法跟 HyFormer 的 Query Decoding/Query Boosting 同构，可以视为 HyFormer 的前驱。InterFormer 比 HyFormer 早，提出 learnable token 作为信号桥梁是核心贡献。

## 三类"统一 backbone"风格的对比

| 风格 | 代表 | 序列与非序列怎么交互 |
|---|---|---|
| 同 token 池 + 参数分化 | OneTrans, HiFormer | 都是 token，attention 矩阵按类型分配 |
| 全局 query 主动检索 | HyFormer | NS 是 query，序列只贡献 KV |
| 中间 token 桥接 | InterFormer | 学一组特殊 token 做信号中转 |

赛题创新奖（Unified Block Innovation）的论文价值，多半在这三类的交叉地带：**中间 token + 参数分化**、**全局 query + KV cache** 这种组合方向。

## HHFT — 最新的 Hierarchical Heterogeneous Feature Transformer (2025)

> arxiv 2511.20235

继续在 Heterogeneous + Hierarchical 这条线上 push。说明 2025-2026 学界还在迭代异构特征的 attention 形式。值得作为对照点放一起。
