# 数据格式说明

## 数据来源与背景

- 来自腾讯广告日志的工业级数据集，已完全匿名化
- 不反映腾讯广告平台的真实生产特征
- 隐私保护：所有稀疏特征为匿名整数 ID，稠密特征为固定长度 float 向量
- 无原始内容（文本、图片、URL）或个人信息

## 数据规模

- 示例数据集：1000 条样本 (demo_1000.parquet)
- 完整数据集：通过竞赛平台（AngelML）提供

---

## 基础字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `user_id` | int64 | 用户 ID |
| `item_id` | int64 | 物品/广告 ID |
| `label_type` | int32 | 标签类型 |
| `label_time` | int64 | 标签时间 |
| `timestamp` | int64 | 时间戳 |

---

## 用户特征 (User Integer Features)

来自 HuggingFace 页面标注的字段：

- `user_int_feats_1`, `user_int_feats_3`, `user_int_feats_4` — int 类型
- `user_int_feats_15` — int_list 类型
- `user_int_feats_48-59` — int 类型
- `user_int_feats_60` — int_list 类型
- `user_int_feats_62-66` — int_list 类型
- `user_int_feats_80` — int_list 类型
- `user_int_feats_82`, `user_int_feats_86` — int 类型
- `user_int_feats_89-109` — 部分为 int_list 类型

---

## 用户稠密特征 (User Dense Features)

- `user_dense_feats_61-66` — float32_list 类型
- `user_dense_feats_87` — float 类型
- `user_dense_feats_89-91` — float32_list 类型

---

## 物品/广告特征 (Item Integer Features)

- `item_int_feats_5-10` — int 类型
- `item_int_feats_11` — int_list 类型
- `item_int_feats_12-13` — int 类型
- `item_int_feats_16` — int 类型
- `item_int_feats_81` — int 类型
- `item_int_feats_83-85` — int 类型

---

## 上下文特征 (Context Features)

来源文档中归类为 Context Features（稀疏），具体字段名需参考数据文件。

---

## 交叉特征 (Cross Features)

来源文档描述为稠密嵌入（float_array），具体字段名需参考数据文件。

---

## 序列特征 (Domain Sequences)

数据包含 4 个域的序列，每个域有多个字段：

| 域 | 字段 |
|----|------|
| Domain A | `domain_a_seq_38-46` (list) |
| Domain B | `domain_b_seq_67-79` (list), `domain_b_seq_88` (list) |
| Domain C | `domain_c_seq_27-37` (list), `domain_c_seq_47` (list) |
| Domain D | `domain_d_seq_17-26` (list) |

---

## 各数据类型的用途

| 数据类型 | 说明 | 处理方式 |
|----------|------|----------|
| 序列特征 | 用户行为序列，反映兴趣动态 | Self-Attention / Transformer |
| 用户特征 | 用户属性（匿名） | Embedding Table |
| 物品特征 | 广告属性（匿名） | Embedding Table |
| 上下文特征 | 当前请求环境（匿名） | Embedding + 特征交叉 |
| 交叉特征 | 稠密嵌入，预计算交互 | 直接拼接输入 |
