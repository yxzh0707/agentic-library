# Memory 系统 (Cosoul)

Memory 系统是 [[cosoul-project]] 的核心组件，负责将海量用户消息沉淀为长期可用的事实、偏好和人物画像，供下游匹配和聊天使用。

## 功能
- **消息沉淀**：将用户产生的海量消息（如聊天记录、行为数据）进行处理和存储，形成结构化的长期记忆。
- **事实提取**：从消息中提取关键事实，如用户偏好、人物关系等，形成可查询的知识库。
- **画像构建**：基于沉淀的数据构建用户画像，用于个性化推荐和代理聊天。

## 在项目中的作用
Memory 系统是 [[cosoul-project]] 实现个性化代理聊天和精准匹配的基础。它为 [[cosoul-agent-system]] 提供记忆支持，使代理能够基于历史交互进行更智能的响应。

## 技术实现
源分析未提供具体的技术细节（如使用的模型、算法），但指出这是项目记忆沉淀的核心组件。相关实现可能涉及自然语言处理、知识图谱等技术。

# Cosoul Agent 系统

Cosoul Agent 系统是 [[cosoul-project]] 的核心组件，采用三层场景架构，使用同一框架但配置不同，以支持多种代理服务场景。

## 三层场景架构
系统支持以下三种场景，通过配置不同实现灵活的代理服务：
1. **self-chat**：用户与自己的代理进行对话，用于自我反思或娱乐。
2. **L3 agent-proxy**：代理作为用户代理，与其他用户或系统进行交互。
3. **Layer C 观察者**：代理作为观察者，监控和分析用户行为，提供洞察。

## 技术特点
- **统一框架**：三层场景共享同一技术框架，通过配置调整实现不同功能，体现了架构的灵活性和可扩展性。
- **与记忆系统集成**：代理系统依赖 [[memory-system-cosoul]] 提供的记忆支持，使代理能够基于历史交互进行智能响应。

## 在项目中的作用
Cosoul Agent 系统是 [[cosoul-project]] 提供用户私域代理服务的关键技术实现，支持多种交互场景，满足不同用户需求。

# AI agent 与推荐系统混合体

AI agent 与推荐系统混合体是一种结合 AI agent 的对话、记忆能力与推荐系统的匹配、排序能力的技术架构，旨在提供用户私域 agent 服务。

## 定义
该混合体融合了两种技术的优势：
- **AI agent**：提供对话、记忆和自主决策能力，使系统能够与用户进行自然交互。
- **推荐系统**：提供精准的匹配和排序能力，使系统能够根据用户偏好和上下文提供个性化内容。

## 应用场景
在 [[cosoul-project]] 中，该混合体用于提供用户私域 agent 服务，包括记忆沉淀和代理聊天功能。用户可以通过代理进行个性化交互，同时系统基于推荐算法提供精准匹配。

## 技术挑战
- **记忆与推荐的集成**：如何将记忆沉淀与推荐算法有效结合，是实现个性化服务的关键。
- **架构设计**：需要设计统一的架构来支持 agent 的对话能力和推荐系统的匹配能力。

# Project Overview

本维基项目旨在系统性地记录和分析推荐系统领域的最新发展，特别是围绕深度学习模型架构和工业应用挑战。当前维基覆盖了从基础概念到具体赛题分析的多个层面，形成了一个关于推荐系统模型设计和优化的综合知识库。

本维基的核心主题之一是**推荐系统模型架构**，特别是如何通过创新的架构设计来解决工业界的实际问题。维基深入分析了 **TAAC2026/KDD Cup 2026** 推荐系统赛题，该赛题的核心挑战是设计一个**统一主干架构**，以打破工业推荐中常见的双轨建模瓶颈。这一分析涵盖了赛题背景、核心要求、模型架构对比（如 OneTrans、HSTU、MTGR）、创新方向（如异构 Transformer、Sample-level Token）以及工程约束（如延迟优化和 Scaling Law 实验）。

此外，维基还记录了关于序列与非序列特征同构处理、双轨建模瓶颈等关键概念的定义和讨论。随着 OneTrans 架构的引入，维基进一步丰富了统一主干架构的技术细节，包括 NS tokenizer、多域序列并入、块内参数共享规则、交叉请求 KV 缓存等具体实现方案。

# AI agent 与推荐系统混合体

AI agent 与推荐系统混合体是一种结合 AI agent 的对话、记忆能力与推荐系统的匹配、排序能力的技术架构，旨在提供用户私域 agent 服务。

## 定义
该混合体融合了两种技术的优势：
- **AI agent**：提供对话、记忆和自主决策能力，使系统能够与用户进行自然交互。
- **推荐系统**：提供精准的匹配和排序能力，使系统能够根据用户偏好和上下文提供个性化内容。

## 应用场景
在 [[cosoul-project]] 中，该混合体用于提供用户私域 agent 服务，包括记忆沉淀和代理聊天功能。用户可以通过代理进行个性化交互，同时系统基于推荐算法提供精准匹配。

## 技术挑战
- **记忆与推荐的集成**：如何将记忆沉淀与推荐算法有效结合，是实现个性化服务的关键。
- **架构设计**：需要设计统一的架构来支持 agent 的对话能力和推荐系统的匹配能力。

# 三层场景架构

三层场景架构是 [[cosoul-agent-system]] 采用的技术框架，通过配置不同支持 self-chat、L3 agent-proxy 和 Layer C 观察者三种场景，体现了架构的灵活性和可扩展性。

## 场景配置
1. **self-chat**：用户与自己的代理进行对话，用于自我反思或娱乐。

- **统一框架**：三层场景共享同一技术框架，通过配置调整实现不同功能。
- **可扩展性**：架构设计支持未来新增场景或功能，易于维护和升级。

## 在项目中的作用
三层场景架构是 [[cosoul-project]] 提供多样化代理服务的基础，使系统能够灵活应对不同用户需求。
