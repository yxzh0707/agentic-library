# Baseline 用到的两个非显然技术：Muon 优化器 + RoPE

本文档分析了 TAAC2026 赛题基线模型 DeepContextNet 采用的两项关键技术：Muon 优化器和 RoPE（旋转位置编码）。这两项技术均从 LLM 训练栈借鉴而来，反映了推荐系统架构向 LLM 范式收敛的趋势。

## Muon 优化器

Muon 是一种通过对隐藏层权重梯度更新进行正交化（使用 Newton-Schulz 迭代）来提升训练效率的优化器，尤其适用于大模型。在 LLM scaling law 测试下，其计算效率约为 AdamW 的 2 倍。Baseline 将其用于 HSTU 等大参数量模块的训练，以提升可扩展性。

## RoPE（旋转位置编码）

RoPE 将绝对位置编码为多个 cos/sin 平面中的旋转矩阵，从而统一表达绝对与相对位置，且无需额外可学习参数。Baseline 将其用于处理异构 token 序列，但其应用方式（编码 token 类型而非时序位置）存在可改进的创新点，如时间感知 RoPE。

## 对赛题的意义

两项技术共同体现了推荐架构向 LLM 范式收敛的趋势，为赛题创新提供了指导。Muon 优化器可提升 backbone 的训练效率，而时间感知 RoPE 可增强位置编码的语义化，两者结合可强化论文奖项的“创新性 + 洞察力”分会。
