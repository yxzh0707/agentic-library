# TAAC2026 / KDD Cup 2026 赛题 framing

本源文档对 TAAC2026 / KDD Cup 2026 推荐系统赛题进行了深入的 framing 分析，核心在于揭示赛题如何通过设计来推动“统一主干架构”这一范式。

## 核心问题与动机

赛题旨在解决工业推荐系统中长期存在的**双轨建模瓶颈**。传统方案中，序列建模（处理用户行为序列）与特征交叉建模（处理用户/物品静态特征）是分离的，导致交互浅、目标不一致、扩展性差和工程复杂。赛题要求设计一个**同构主干 + 可堆叠统一 block** 的模型，同时处理序列 token（多域行为序列）和非序列字段 token（广告/上下文/交叉特征），输出 pCVR。

## 硬约束与数据形态

赛题设置了严格的工程约束：
- **主指标**：ROC-AUC，低于 0.50 不上榜。
- **延迟约束**：推理延迟有上限，超时作废，禁止无脑堆层和 KV 长序列裸跑。
- **禁止 ensemble**：不能靠投票拉分。
- **同分规则**：按延迟升序打破平局，延迟是第二指标。
- **论文奖**：设立 Unified Block 创新和 Scaling Law 创新两个奖项。

数据形态方面，每条样本包含用户、上下文和目标广告三元组。序列特征被拆分为 4 个域（A/B/C/D），非序列特征有 70 列（用户整数/稠密特征、物品整数特征），上下文特征被合并到用户/物品整数特征中。

## Framing 视角与研究轴

本源提出了一个核心论点：赛题的本质是验证“将序列 token 和字段 token 投到同一表示空间，让 self-attention/cross 在同一层发生”这一范式，是否能在延迟可控的前提下获得比传统双轨建模更高的 AUC。

基于此，后续资料摄入和模型设计应围绕三个研究轴展开：
1. **同构 token 化**：如何将序列事件和非序列字段编码成可被同一 block 消化的统一 token 表示。
2. **统一 block 设计**：单个 block 如何同时承担序列内自注意力、非序列内特征交叉以及两类 token 之间的交叉注意力。
3. **延迟可控的 scaling**：在延迟预算约束下，如何通过模型深度/宽度扩展来提升性能，避免工程风险。

本源文档为赛题分析提供了清晰的框架，并与现有维基中的概念（如双轨建模瓶颈、统一主干架构）高度一致，强化了这些概念在具体场景下的应用价值。
