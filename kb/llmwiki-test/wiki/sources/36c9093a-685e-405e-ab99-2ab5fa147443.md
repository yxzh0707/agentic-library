# Sample Is Feature — 一个对赛题最有可能拿"创新分"的新 axis

这篇笔记介绍了一篇挑战 item-level token 假设的论文，为赛题创新提供了新方向。核心是介绍论文《Sample Is Feature》，它挑战了统一推荐模型中默认的 item-level token 假设，指出其丢失上下文和异构 token 处理的局限。解法是引入 sample-level token，将每个历史样本作为整体编码。笔记分析了该思路与赛题数据的契合度，指出赛题数据隐含约束但可通过代理构造近似 sample-level token。最后提出了两个创新口子：论文级（重新形式化 sample-level token）和工程级（纳入 token 化层级），并提醒了序列变短可能影响速度的风险。

论文链接：https://arxiv.org/abs/2604.15650
