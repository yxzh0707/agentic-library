# 赛题经典 Baseline 吸收策略

本源文档系统阐述了如何将 TAAC2026 赛题中列出的经典 Baseline 模型（DIN、DIEN、DCN、DCNv2、SASRec、BERT4Rec）的核心技巧吸收进统一主干架构，以提升赛题表现并增强模型的理论深度。

## 核心论点

经典模型在赛题中不应仅被视为被击败的对象，而是统一主干必须内化的能力。统一主干的设计目标是在足够窄/浅的极限下能退化为这些经典模型，这体现了“尊重经典”与“展示创新”的平衡。

## 吸收策略

### 序列侧
- **DIN (Deep Interest Network)**：核心技巧为 Target Attention。在统一 Token 流中，让 Candidate Ad Token 对历史行为 Token 进行加权求和，实现用户表示因候选而异，从而在统一框架内复活 DIN 的核心。
- **DIEN (Deep Interest Evolution Network)**：核心技巧为 Auxiliary Loss。可将预测下一行为的辅助任务作为廉价损失函数融入统一主干，与 TransAct V2 的 Next Action Loss 思路一致。
- **SASRec**：核心技巧为 Causal Mask。可直接复用于统一主干，与 OneTrans 的因果注意力机制一致。
- **BERT4Rec**：核心技巧为 Cloze 任务。可考虑用于预训练阶段，但需确认是否违反赛题“禁 Ensemble”的规则。

### 非序列侧
- **DCN (Deep & Cross Network)**：核心技巧为显式特征交叉。
- **DCNv2**：核心技巧为矩阵形式的交叉网络，是工业部署主力。统一主干中的非序列 Token 间的 Cross Attention 可视为 DCNv2 的泛化，其中 Attention 是学习到的核函数，可能表达力更强。

## 证据支持
- 引用经典论文（如 DIN 的 arXiv 编号）和工业部署案例（如阿里、Google）。
- 指出 OneTrans 与 DCNv2 + DIN 对比的 AUC 提升（+1.53%），表明 DCNv2 是当前最强的非序列 Baseline。
