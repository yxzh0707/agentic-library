# TAAC2026 赛题全览（问题导向版）

本源文档提供了 TAAC2026 赛题的全面概述，核心任务是在单一同构主干网络中，用统一 block 同时处理多域用户行为序列和非序列多字段特征，输出 pCVR。文档详细分析了赛题的难点（双轨建模瓶颈）、评测标准与约束（ROC-AUC、推理延迟、禁止集成）、数据结构总览，以及两种数据格式（官方 JSON 与 HuggingFace Parquet）的对比。最后，总结了建模的五大关键挑战：统一 tokenization、同构 block 设计、多域序列融合、延迟约束、稠密+稀疏统一。

该文档为现有 Wiki 中的 [[taac2026-kdd-cup-2026]] 页面提供了权威的全览和问题导向分析，强化了 [[统一主干架构]]、[[双轨建模瓶颈]] 等概念在具体赛题中的应用。
