# HSTU — 赛题 baseline 的核心 block，也是 scaling law 的骨架

本源文档详细介绍了 Meta 提出的 HSTU 架构，该架构是 TAAC2026 赛题 baseline 的核心组件，也是推荐域 Scaling Law 创新的自然起点。

## 核心内容

### 架构描述
HSTU 每层包含三个子层：
1. **Pointwise Projection**：token-wise 投影，每个 token 独立处理，无跨 token 交互。
2. **Spatial Aggregation**：真正进行 token 间交互的子层，使用 **pointwise normalization** 替代标准 softmax，以解决推荐场景中高基数、非平稳 token（如 item ID）的归一化问题。
3. **Pointwise Transformation**：token-wise 变换。

### 速度优势
- 在 8192 长序列下，比 FlashAttention2 Transformer 快 **5.3x ~ 15.2x**。
- 通过 M-FALCON 微批方案，相同推理预算下可服务 **285x** 更复杂的模型，端到端再加速 1.50x ~ 2.48x。
- 这些数字为赛题的延迟约束提供了工程预算上限。

### 与 TAAC2026 赛题的关系
- HSTU 是 TAAC2026 baseline GitHub 仓库（作者 suyanli220）的核心，直接处理 [CLS, User, Item, Sequence] 四类 token。
- 它是推荐域 Scaling Law 创新奖的自然 baseline，已证明能平稳提升 AUC。
- **改进机会**：HSTU 缺乏显式 S/NS 参数区分，可结合 OneTrans 的“S 共享 + NS 独占”规则进行创新。

### 与 baseline 的关系
TAAC2026 baseline 结合了 HSTU 与 Muon 优化器，配置为 HIDDEN_DIM=128, BLOCK_DEPTH=4, lr=2e-4, SESSION_GAP=1800s，作为起跑线。
