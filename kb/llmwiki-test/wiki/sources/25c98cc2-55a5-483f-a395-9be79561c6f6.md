# TAAC2026 综合作战计划：模型选型、结构设计与奖项策略

本源文件是针对 TAAC2026/KDD Cup 2026 推荐系统赛题的一份综合性、可执行的作战计划。它基于赛题的已知事实（单一同构 backbone、输出 pCVR、AUC+延迟双约束、禁 ensemble、两个论文奖），整合了多篇相关论文的技术要点，提出了从模型选型、Tokenizer 设计、Block 内部结构、训练目标、延迟优化到 Scaling Law 实验的完整方案。

## 核心主张

1.  **模型选型**：首选 **MTGR** 作为 Backbone。理由是其起步代价最低、保留赛题数据中的 Cross Feature 语义、有工业 baseline 数字，且结合了 HSTU 的速度优势与 GLN 的优化。
2.  **架构设计**：采用**分层 Tokenizer**（序列侧 timestamp-aware interleave，非序列侧 group-wise）与**统一 Block**（结合 HSTU 的延迟优势与 MTGR 的 GLN）。
3.  **训练与优化**：主损失为 CVR BCE，辅以自监督（Next Action Prediction）与多任务（CTR BCE）损失；延迟优化从训练阶段锁定（causal attention + KV cache）。
4.  **实验与奖项**：通过**三档 Scaling Law 实验**（小/中/大模型，扫 W、D、token 数维度）生成论文骨架，明确两个论文奖的创新点 framing。

## 关键技术细节

*   **Tokenizer 设计**：
    *   序列侧：4 域 timestamp-aware interleave，每事件 = item_id emb + action_type emb + time_bucket emb（拼接），加 4 维 domain type embedding。
    *   非序列侧：group-wise（OneTrans 风），分 user 组、item 组、candidate 组，分别压缩为 token。
*   **Block 内部结构**：使用 HSTU 的 pointwise normalization 拿到延迟优势，Layer normalization 按语义分组（MTGR 的 GLN），参数规则遵循序列 token 共享、NS token 独占（借自 OneTrans），并使用 dynamic mask 隔离不该互看的 token。
*   **延迟优化**：训练即 causal attention，推理时启用 cross-request KV cache，结合 FlashAttention-2 与 BF16 混合精度，序列侧采用两阶段计算。
*   **论文奖项策略**：
    *   **Unified Block Innovation Award**：组合 MTGR 的 GLN、OneTrans 的参数分化、HyFormer 的 Query Decoding 作为层间池化算子。
    *   **Scaling Law Innovation Award**：在赛题数据上跑出 (FLOPs, AUC) 曲线，重点研究 NS token 数量 T 这个新维度的 scaling 行为。

## 不确定项与后续验证

计划明确列出了需要优先验证的不确定项，包括单 sample 序列长度分布、实际延迟预算、4 个 domain 的事件量比例、Cross feature 的物理含义等，这些是架构决策前必须澄清的问题。

本源文件为 TAAC2026 赛题的执行提供了清晰的路线图，并强调了基于实验结果验证假设的重要性。
