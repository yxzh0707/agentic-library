# 腾讯广告赛题 DeepContextNet 基线模型拆解

本文拆解了腾讯广告赛题的 DeepContextNet 基线模型架构、关键技巧与三个主要改进方向。

## 架构四阶段

1. **统一嵌入层**：稀疏类别 ID + 稠密向量映射到共享 d 维潜空间
2. **序列合成**：`Item_ID + Action_Type + Temporal_Bucket` 三个 embedding **加法融合**成一个事件 token
3. **深度交互**：多个 HSTU 块 + Rotary positional bias，处理 `[CLS, User, Item, Sequence]` token
4. **投影头**：非线性瓶颈层 → CTR 概率

## 关键技巧

- **全局 CLS 集成**：CLS token 聚合 user 静态属性 + item 特征 + 行为序列，做最终预测
- **时间感知衰减**：对数时间分桶捕获新近性
- **混合精度训练**：torch.cuda.amp，省显存
- **Muon 优化器**：SVD 基础正交化梯度更新

## 暴露的三个改进方向

1. **序列合成是简单加法**：三个语义不同的信号压缩成同一向量，可优化为拼接+投影或独立维度切片。
2. **非序列特征只占两个 token**：70 列特征压缩为 User/Item 两个 token，可参考 OneTrans 的 group-wise tokenizer 扩展。
3. **CLS 是唯一的预测出口**：易被序列侧主导，可引入 candidate item token 参与预测。

## 对照实验设计

从低到高代价：加 Group-Layer Normalization、扩展 NS token、token-specific 参数、引入 cross-request KV 缓存，目标是相同 FLOPs 下 AUC 增益。
