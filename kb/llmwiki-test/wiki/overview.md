# Project Overview

本维基项目旨在系统性地记录和分析推荐系统领域的最新发展，特别是围绕深度学习模型架构和工业应用挑战。当前维基覆盖了从基础概念到具体赛题分析的多个层面，形成了一个关于推荐系统模型设计和优化的综合知识库。

本维基的核心主题之一是**推荐系统模型架构**，特别是如何通过创新的架构设计来解决工业界的实际问题。维基深入分析了 **TAAC2026/KDD Cup 2026** 推荐系统赛题，该赛题的核心挑战是设计一个**统一主干架构**，以打破工业推荐中常见的双轨建模瓶颈。这一分析涵盖了赛题背景、核心要求、模型架构对比（如 OneTrans、HSTU、MTGR）、创新方向（如异构 Transformer、Sample-level Token）以及工程约束（如延迟优化和 Scaling Law 实验）。

此外，维基还记录了关于序列与非序列特征同构处理、双轨建模瓶颈等关键概念的定义和讨论。随着 OneTrans 架构的引入，维基进一步丰富了统一主干架构的技术细节，包括 NS tokenizer、多域序列并入、块内参数共享规则、交叉请求 KV 缓存等具体实现方案。

随着新赛题和新技术的不断涌现，维基持续更新以反映该领域的最新进展。最近，维基引入了**腾讯广告赛题 DeepContextNet 基线模型**的拆解分析，提供了四阶段架构和关键技巧，并指出了三个主要改进方向：序列合成优化、非序列特征扩展和多预测出口设计。同时，维基还整合了**推荐系统赛题综合解决方案簇分析**，该簇围绕 TAAC2026/KDD Cup 2026 赛题，提供了一个包含延迟优化、架构统一和工程实战三大支柱的综合性作战计划，进一步强化了从理论到实践的完整知识链条。

最新引入的 **TAAC2026 / KDD Cup 2026 赛题 framing** 分析，将赛题的抽象要求转化为三个可操作的研究轴：同构 token 化、统一 block 设计和延迟可控的 scaling。这一分析为后续的模型设计和资料摄入提供了清晰的分类框架，进一步丰富了维基在赛题分析和模型架构设计方面的知识体系。

最新引入的 **综合作战计划 v2**，整合了第二轮深度搜索后的技术要点，提出了一个分阶段的实验路线（三档实验路线），从基础 baseline 跑通到冲击论文奖项，并详细阐述了 Token 化层设计、训练目标、工程预算及论文奖项策略。该计划引入了新的实体（如 Kunlun、FAT、Sample Is Feature、TransAct V2、HyFormer、Wukong）和具体技术细节（如 Token 化设计、训练目标公式），极大地扩展了维基的知识体系。

最新引入的 **TAAC2026 赛题全览（问题导向版）**，提供了赛题的权威全览和问题导向分析，详细说明了核心任务、评测标准与约束、数据结构总览、两种数据格式对比以及五大建模挑战。该文档为现有 Wiki 中的 [[taac2026-kdd-cup-2026]] 页面提供了权威的全览和问题导向分析，强化了 [[统一主干架构]]、[[双轨建模瓶颈]] 等概念在具体赛题中的应用，并引入了 [[taac2026-data-format]] 和 [[taac2026-modeling-challenges]] 两个新页面。

最新引入的 **赛题经典 Baseline 吸收策略**，系统阐述了如何将 DIN、DIEN、DCN、DCNv2、SASRec、BERT4Rec 等经典推荐模型的核心技巧吸收进统一主干架构。这一分析强化了“经典模型在赛题中不是被打败的对象，而是统一主干必须能包含的能力”的设计哲学，并提供了序列侧和非序列侧的具体吸收策略，如 Target Attention、Auxiliary Loss、Causal Mask、Cross Attention 作为 DCNv2 泛化等。这一内容进一步丰富了维基在模型架构设计和创新方面的知识体系。

最新引入的 **TAAC2026 综合作战计划**，整合了多篇相关论文的技术要点，提出了从模型选型、Tokenizer 设计、Block 内部结构、训练目标、延迟优化到 Scaling Law 实验的完整方案。该计划强调以 MTGR 为首选 Backbone，采用分层 Tokenizer 设计和三档实验路线，明确了 Unified Block Innovation 和 Scaling Law Innovation 两个论文奖项的 framing 策略。这一内容进一步强化了维基在赛题执行和工程实践方面的知识体系。

最新引入的 **TAAC2026 统一主干架构设计簇分析**，总结了围绕 TAAC2026 赛题的 14 个成员笔记，核心是要求使用单一、同构的主干网络同时处理序列行为建模与非序列特征交互，以解决工业推荐中“双轨建模”的瓶颈。该簇分析以 [[25c98cc2-55a5-483f-a395-9be79561c6f6]]（综合作战计划）为中心枢纽，协调其他成员的讨论，进一步强化了维基在赛题分析和模型架构设计方面的知识体系。

最新引入的 **Sample Is Feature** 分析，挑战了现有统一推荐模型中默认的 **item-level token 假设**，指出其丢失上下文和异构 token 处理的局限，并引入 **sample-level token** 作为更优的建模轴。这一分析为 TAAC2026 赛题提供了新的创新方向，特别是在统一主干架构设计中，通过代理构造近似实现 sample-level token，并提出了论文级和工程级两个创新口子。同时，提醒了序列变短可能影响速度的风险，需要进一步实验验证。

最新引入的 **Baseline 用到的两个非显然技术：Muon 优化器 + RoPE** 分析，深入探讨了 DeepContextNet 基线模型采用的两项关键技术。Muon 优化器通过正交化隐藏层权重更新来提升训练效率，尤其适用于大模型；RoPE 位置编码则用于处理异构 token 序列，但其非标准用法（token type encoding）为赛题选手提供了改进空间（如时间感知 RoPE）。这两项技术均从 LLM 训练栈借鉴而来，反映了推荐架构向 LLM 范式收敛的趋势，对赛题创新有指导意义。

最新引入的 **推荐域 Scaling Law 全图谱**，系统梳理了2024-2026年推荐域Scaling Law的关键工作，为TAAC2026赛题的“Scaling Law Innovation Award”提供了清晰的论文坐标系和选边建议。该图谱强调了曲线斜率对比、5个Scaling维度（W/D/T/L/N）以及效率科学化（MFU、Rademacher复杂度）的重要性，进一步扩展了维基在Scaling Law理论和实验方面的知识体系。

最新引入的 **HSTU — 赛题 baseline 的核心 block，也是 scaling law 的骨架**，详细介绍了 Meta 提出的 HSTU 架构，该架构是 TAAC2026 赛题 baseline 的核心组件，也是推荐域 Scaling Law 创新的自然起点。HSTU 通过 pointwise normalization 替代 softmax，解决了推荐场景高基数 token 的归一化问题，实现了比 FlashAttention2 快 5.3x~15.2x 的速度优势，并提供了 S/NS 参数区分的改进机会。

这些内容共同构成了一个关于推荐系统模型设计和优化的综合知识库，为研究人员和工程师提供了有价值的参考。
