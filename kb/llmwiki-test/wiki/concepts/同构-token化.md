# 同构 token 化

同构 token 化是指将用户的多域行为序列和广告/上下文等非序列字段编码成可被同一模型块消化的统一 token 表示的技术概念。这是实现[[统一主干架构]]的前提，决定了模型输入的形态。

## 定义与背景

在 TAAC2026 赛题中，序列特征被拆分为 4 个域（A/B/C/D），非序列特征有 70 列（用户整数/稠密特征、物品整数特征）。传统双轨建模中，这两类信号是分开处理的。同构 token 化的目标是将它们统一到同一表示空间中。

## 技术实现

同构 token 化通常涉及以下步骤：
1. **序列事件编码**：将每个序列事件（如 item_id、action_type、timestamp）编码为一个 token。
2. **非序列字段编码**：将用户/物品的静态特征（如整数特征、稠密向量）编码为 token。
3. **统一嵌入层**：使用[[统一嵌入层]]将稀疏类别 ID 和稠密向量映射到共享潜空间，形成统一的 token 表示。

## 在赛题中的应用

在 TAAC2026 赛题中，同构 token 化是三个研究轴之一。它确保序列 token 和字段 token 能被同一[[统一 block 设计]]处理，从而打破双轨建模的瓶颈。
