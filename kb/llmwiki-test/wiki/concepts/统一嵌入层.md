# 统一嵌入层

统一嵌入层是 DeepContextNet 架构的第一阶段，负责将稀疏类别 ID 和稠密向量映射到共享的 d 维潜空间。

## 功能

- 将不同来源的特征（稀疏 ID 和稠密向量）统一到同一表示空间。
- 为后续的序列合成和深度交互提供一致的输入格式。

## 重要性

这是特征统一处理的基础，使得模型能够同时处理序列和非序列特征。
