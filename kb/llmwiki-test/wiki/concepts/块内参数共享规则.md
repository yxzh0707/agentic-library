# 块内参数共享规则

块内参数共享规则是 OneTrans 的核心创新，用于实现“统一 block”的关键 trick。其核心思想是按 token 类型分配参数预算，避免语义平均化。

## 规则定义
- **序列 token（S-tokens）**：共享一组参数 W^S。
- **非序列 token（NS-tokens）**：每个 token 独占参数 W_{NS,i}。
公式：W_i = W^S 当 i ≤ L^S，否则 W_{NS,i}。

## 设计直觉
- 序列里的 event 是同分布的，共享投影合理。
- 非序列字段每个语义角色不同，独占参数避免被平均掉。

## 赛题应用
在 KDD Cup 2026 赛题中，此规则是实现“统一主干架构”的关键，确保不同语义角色的 token 得到针对性处理。
