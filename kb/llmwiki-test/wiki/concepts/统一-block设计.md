# 统一 block 设计

统一 block 设计是指单个模型块同时承担序列内自注意力、非序列内特征交叉以及两类 token 之间的交叉注意力的技术概念。这是 TAAC2026 赛题“可堆叠统一 block”的核心，决定了模型的计算逻辑。

## 定义与背景

在传统双轨建模中，序列建模和特征交叉建模使用不同的模型块。统一 block 设计旨在将这些功能集成到一个块中，从而实现更高效的交互和更简单的工程实现。

## 技术实现

统一 block 设计通常涉及以下组件：
1. **序列内自注意力**：处理序列 token 之间的依赖关系，类似于[[异构-transformer]]中的自注意力机制。
2. **非序列内特征交叉**：处理用户/物品静态特征之间的交互，类似于[[深度交互]]中使用多个 HSTU 块处理 token。
3. **交叉注意力**：处理序列 token 和字段 token 之间的交互，确保两类信号在统一空间中融合。

## 在赛题中的应用

在 TAAC2026 赛题中，统一 block 设计是三个研究轴之一。它与[[同构 token 化]]结合，确保模型能同时处理序列和非序列输入，从而打破双轨建模的瓶颈。
