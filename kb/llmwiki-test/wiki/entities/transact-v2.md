# TransAct V2

TransAct V2 是一篇论文（2506.02267）提出的技术概念，在 TAAC2026 赛题的综合作战计划中用于 **Next Action Loss** 的自监督学习。

在训练目标中，TransAct V2 提供 Next Action Loss 辅助，与 BCE 损失和蒸馏损失结合，形成多任务+自监督+蒸馏的综合损失函数。
