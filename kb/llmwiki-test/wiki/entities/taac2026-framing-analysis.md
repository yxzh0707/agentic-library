# TAAC2026 赛题 Framing 分析

TAAC2026 赛题 Framing 分析是指对 TAAC2026 / KDD Cup 2026 推荐系统赛题进行问题定义和研究方向梳理的分析方法。该分析的核心在于将赛题的抽象要求转化为可操作的研究轴，为模型设计和资料摄入提供分类框架。

## 分析视角

本分析将赛题本质定义为验证“将序列 token 和字段 token 投到同一表示空间，让 self-attention/cross 在同一层发生”这一范式。其核心论点是：在延迟可控的前提下，统一架构能否获得比传统双轨建模更高的 AUC。

## 三个研究轴

基于上述视角，分析提出了三个关键研究轴：
1. **同构 token 化**：研究如何将用户的多域行为序列和广告/上下文等非序列字段编码成统一的 token 表示，以便被同一模型块消化。
2. **统一 block 设计**：研究单个模型块如何同时承担序列内自注意力、非序列内特征交叉以及两类 token 之间的交叉注意力。
3. **延迟可控的 scaling**：研究在推理延迟有硬性上限的约束下，如何通过模型深度/宽度扩展来提升性能，同时避免工程风险。

这些研究轴为后续的模型设计和资料摄入提供了清晰的分类标准，并与现有维基中的概念（如双轨建模瓶颈、统一主干架构）紧密相连。
