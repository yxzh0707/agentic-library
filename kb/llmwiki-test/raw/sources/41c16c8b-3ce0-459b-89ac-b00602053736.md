# Baseline 用到的两个非显然技术：Muon 优化器 + RoPE

baseline (DeepContextNet) 选了两个不是 ML 入门级、但赛题选手如果不熟会盲选错的技术。值得单独搞清楚。

## Muon 优化器

### 它是什么
Keller Jordan 等人 2024 末发布的优化器。核心：**对隐藏层权重的梯度更新做正交化**——把更新矩阵投到正交矩阵流形上。
- 实现细节：用 **Newton-Schulz 迭代**而不是 SVD 做正交化（SVD 太慢，NS 几次矩阵乘就够）
- 适用范围：仅用于隐藏层 2D 权重；嵌入和 LayerNorm 仍用 AdamW
- 效率：在 LLM scaling law 测试下，约 **2x AdamW 的 compute 效率**

### 为什么 baseline 用 Muon
两个推测：
1. baseline 作者借用了 LLM 圈最近的优化器进展，HSTU 这种"trillion params"风的模型确实从 Muon 受益更明显
2. 推荐场景的 embedding 大头不归 Muon 管，它只优化深度 block 的权重——刚好是赛题里堆 HSTU 那部分

### 赛题里的取舍
- **保留 Muon**：跟 baseline 公平对照，且 2x 训练效率意味着同样时间能扫更多超参
- **替换 AdamW**：稳定性和文献支持都更多，做实验更容易复现
- **混合**：Muon 用于 backbone，AdamW 用于 embedding/output（这是 Muon 论文推荐的 pattern）

### 资源
- 论文：https://arxiv.org/pdf/2502.16982 (Muon is Scalable for LLM Training, Moonshot AI 2025)
- 博客：https://kellerjordan.github.io/posts/muon/
- 代码：https://github.com/KellerJordan/Muon

## Rotary Positional Embedding (RoPE)

### 它是什么
Su 等人 2021 提出（RoFormer, arxiv 2104.09864），现在是 LLaMA/Gemma/Mistral 默认位置编码。核心：**把绝对位置编码成多个 cos/sin 平面里的旋转矩阵，相对位置自动从相位差里读出**。

### 关键性质
- 绝对 + 相对位置统一表达
- **零额外可学习参数**（相比 learned positional embedding）
- 序列长度可外推（4k 训练 → 100k+ 推理只需 angle scaling）
- 能兼容线性 attention 形式

### baseline 把它用在哪
baseline 的"deep interaction"阶段用 HSTU + Rotary positional bias 处理 [CLS, User, Item, Sequence] 这串异构 token。

**注意一个细节**：标准 RoPE 是给"位置"编码的，但 baseline 的 token 序列里 CLS/User/Item 不是"序列位置"——这意味着 baseline 实际上把 RoPE 用作了**"token type encoding"或者"row index encoding"**而非真正的时序位置。

这点对赛题选手很重要：
- 如果你保 baseline 这种用法，就需要解释清楚"为什么旋转编码能区分 token 类型"
- 如果你改成 timestamp-based RoPE（即按事件 timestamp 的 log 值编码相位），物理意义更清晰，但要重新调试

### 时间感知 RoPE 的具体做法
- 把每个事件的 timestamp 取对数 → 映射到一个连续位置 t
- RoPE 用这个连续 t 而非整数 i 来生成相位
- 等价于 baseline 的"对数时间分桶"但更平滑

这是个**可发表的细节改进**（FAT/Selective RoPE 这类工作正在沿这条线推进）。

### 资源
- 原论文：https://arxiv.org/abs/2104.09864
- Selective RoPE: https://arxiv.org/abs/2511.17388 (2025 末，挑选哪些维度做旋转)

## 把 Muon 和 RoPE 放一起看

两者都是从 **LLM 训练栈**借来的技术，不是推荐原生的。这反映赛题方期待的方向：**让推荐架构同 LLM 训练范式收敛**。

如果你的提交里能同时讲清楚：
1. 用 Muon 让 backbone scale 时训练成本可控
2. 用 timestamp-aware RoPE 让位置编码语义化
3. 跟 OneTrans/HyFormer 的架构对照下保留这些 LLM 借来的组件

那论文奖的"创新性 + 洞察力"分会更稳。
