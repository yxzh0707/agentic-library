# 推荐域 Scaling Law 全图谱（赛题创新奖二的论文坐标系）

赛题第二个论文奖叫 **Scaling Law Innovation Award**。这个奖项有意义的前提是评审会拿你的曲线跟"现有 scaling law"对照——下面是过去 24 个月把这条线推到哪里的全部主要工作。投稿前必须把自己的位置在这张图上找出来。

## 时间线（按贡献维度）

### 2024 — 把"scaling law"这个词搬进推荐域
- **Wukong** (Meta, 2403.02545)：堆叠 FM + 同时增 W/D，跨两个数量级 compute 保持斜率正。**奠基**。
- **HSTU** (Meta, 2402.17152)：序列侧 scaling 的事实标准；万亿参数；pointwise norm 让大词表稳定。

### 2025 — 工业部署化 + 算子级优化
- **RankMixer** (字节, 2507.15551)：TokenMixer 替换 self-attention，硬件感知；AUC ~ params 总量。
- **TokenMixer-Large** (字节, 2602.06563)：把 RankMixer 推到工业级。
- **MTGR** (美团, 2505.18654)：HSTU + Group-LN + dynamic mask，保留 cross feature 的工业版。
- **OneTrans** (字节, 2510.26104)：S/NS 参数分化的 unified transformer，**赛题官方推荐**。

### 2026 — 多个并行的"统一架构 + scaling"工作（这是赛题真正的同时代竞争）
- **MixFormer** (字节, 2602.14110)：明确"co-scaling dense + sequence"，user-item 解耦优化推理。
- **HyFormer** (字节, 2601.12681)：抖音搜索 3B 样本，AUC 0.6489 略胜 OneTrans。
- **Kunlun** (Meta + OpenAI, 2602.10016)：MFU 17%→37%，scaling 效率 2x。GDPA + Hierarchical Seed Pooling + Sliding Window + Compute Skip。**当前最贴 GPU 硬件优化的**。
- **ULTRA-HSTU / "Bending the Scaling Law Curve"** (2602.16986)：HSTU 系统协同设计，5x 训练 + 21x 推理加速。
- **EST** (阿里, 2602.10811)：Lightweight Cross-Attention + Content Sparse Attention，Taobao +3.27% RPM。
- **FAT / Structured Expressivity** (阿里, 2511.12081)：**第一篇基于 Rademacher 复杂度的 CTR scaling law 形式化**。Field-Aware Transformer。+0.51% AUC，+2.33% CTR。
- **UniMixer** (快手, 2604.00590)：把 Heterogeneous Attention / TokenMixer / Wukong 统一成同一参数化框架，提供 scaling 设计指南。
- **Sample Is Feature** (2604.15650)：维度突破——从 item-level token 走到 sample-level token，挑战之前所有 scaling 都在 item 粒度的假设。

## 这张图给赛题的三个直接结论

### 1. 你的 (FLOPs, AUC) 曲线要跟下面这几条比
- HSTU 单序列侧 scaling（已知斜率）
- Wukong 单 NS 侧 scaling（已知斜率）
- OneTrans / MixFormer / HyFormer 的 unified scaling（同时代基准）
- FAT 的 Field-Aware scaling（可能是 2026 上界）

仅展示 AUC 高于 baseline 是不够的，**要展示斜率**。

### 2. Scaling 维度有 5 个，不是 2 个
现有论文已覆盖：
- W (width) — Wukong 起就在 scale
- D (depth) — HSTU、RankMixer
- T (token 数) — RankMixer 正式列入
- L (sequence length) — TWIN V2、ULTRA-HSTU
- N (sample 内 token 粒度) — Sample Is Feature 新维度

赛题里 NS token 数（70 个 feature 怎么切成几个 token）和 sample-level granularity 是相对未被探索的，**最容易做出新颖性**。

### 3. 效率的"科学化"已经开始
- Kunlun 提出 **MFU 是核心瓶颈**（GPU 实际利用率），不是 FLOPs
- FAT 用 **Rademacher 复杂度**给 CTR 形式化 scaling
- EST 用 **Lightweight Cross-Attention** 做有理论根的剪枝

赛题里 Scaling Law Award 的论文如果只画曲线没给理论解释，分量不够。**至少要解释为什么这条曲线在赛题数据上成立**。

## 选边建议
首选 baseline：MTGR（HSTU+GLN+dynamic mask）→ 改 OneTrans 的 S/NS 参数分化 → 加 Kunlun 的 MFU 优化 → 跑三档画曲线 → 在论文里跟 FAT 的 Rademacher framing 对话。

这条路径每一步都有现成参考，不需要发明新理论，但组合起来能讲清"赛题数据上的 scaling"。
